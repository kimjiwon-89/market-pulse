## 1. 이 문서를 읽는 기준

이 장은 단일 팩터 전략을 넘어 섹터 중립, 마법공식, 이상치 처리, 팩터 정규화, 멀티팩터 포트폴리오를 다룬다.

현재 Market Pulse의 중심은 `MP_CORE` 단일 코어 모델이므로, 이 장의 내용을 모두 하나의 전략으로 합치면 모델 목적이 흐려질 수 있다. 따라서 아래처럼 분류한다.

| 분류 | 내용 | 판단 |
|---|---|---|
| `MP_CORE_NOW` | 섹터 중립 rank, 이상치 처리, rank z-score 정규화 | 지금 모델 feature engineering에 바로 필요 |
| `MP_CORE_LATER` | 밸류/퀄리티 결합, QVM score | 재무 데이터 구축 후 보조 피처로 사용 |
| `NEXT_MODEL` | 마법공식, QVM 멀티팩터 포트폴리오 | 별도 전략/벤치마크로 분리 |
| `REFERENCE_ONLY` | 원문 R 구현 세부 문법 | 개념만 참고 |

## 2. 글의 핵심

원문은 기본 팩터 전략의 약점을 보완하는 방법을 설명한다.

- 모멘텀 같은 단일 팩터는 특정 섹터로 쏠릴 수 있다.
- 섹터 중립화는 같은 섹터 안에서 팩터 강도를 비교해 섹터 편중을 줄인다.
- 밸류와 퀄리티는 서로 반대 성격이 있지만, 둘을 결합하면 "좋은 회사를 싸게 사는" 전략이 된다.
- 마법공식은 이익수익률과 투하자본수익률을 결합한 대표적인 밸류+퀄리티 전략이다.
- 이상치는 트림 또는 윈저라이징으로 다룰 수 있다.
- 여러 팩터를 합칠 때는 단순 rank 합보다 rank를 z-score로 정규화한 뒤 결합하는 것이 안정적이다.
- Quality, Value, Momentum을 결합한 QVM 포트폴리오는 멀티팩터의 기본 예시다.

## 3. 모델별 분류

| 원문 주제 | MP_CORE 반영 | 다음 모델 후보 | 판단 |
|---|---|---|---|
| 섹터 중립 포트폴리오 | `MP_CORE_NOW` | 모든 팩터 모델 공통 기법 | 현재 모델에 중요 |
| 밸류-퀄리티 관계 | `MP_CORE_LATER` | `MP_MAGIC`, `MP_QVM` | 재무 데이터 이후 |
| 마법공식 | 보조 벤치마크 | `MP_MAGIC_FORMULA` | 별도 장기 포트폴리오 |
| 트림/윈저라이징 | `MP_CORE_NOW` | 모든 모델 공통 전처리 | 지금 필요 |
| rank z-score 결합 | `MP_CORE_NOW` | 모든 멀티팩터 공통 | 지금 필요 |

현재 우선순위:

1. `MP_CORE_NOW`: 가격/유동성/수급 피처에 섹터 중립 rank와 winsorizing 적용
2. `MP_CORE_LATER`: value/quality 피처가 생기면 rank z-score 방식으로 결합
3. `NEXT_MODEL`: 마법공식과 QVM을 독립 전략으로 만들어 `MP_CORE`와 성과 비교

## 4. 섹터 중립 포트폴리오

원문은 12개월 모멘텀 상위 30종목을 고르면 특정 섹터에 종목이 몰릴 수 있음을 보여준다. 모멘텀은 섹터 단위로 함께 움직이는 경우가 많기 때문이다.

섹터 중립화 절차:

1. 종목별 12개월 수익률을 계산한다.
2. 종목 마스터에 섹터 정보를 붙인다.
3. 섹터별 그룹을 만든다.
4. 각 섹터 안에서 수익률을 z-score로 표준화한다.
5. 전체 종목을 섹터 내 표준화 점수 기준으로 다시 랭킹한다.
6. 상위 종목을 선택한다.

정규화 개념:

```text
sector_z_score = (stock_factor - sector_mean_factor) / sector_std_factor
```

이렇게 하면 "전체 시장에서 강한 종목"이 아니라 "자기 섹터 안에서 강한 종목"을 고르게 된다.

### MP_CORE_NOW 적용

섹터 중립화는 현재 모델에 바로 넣는 것이 좋다.

피처 후보:

```text
ret_60d_rank_market
ret_60d_rank_sector
ret_252d_rank_market
ret_252d_rank_sector
vol_60d_rank_market
vol_60d_rank_sector
liquidity_rank_market
liquidity_rank_sector
sector_z_momentum
sector_z_liquidity
sector_z_risk
```

활용:

- 특정 섹터 호황기에 포트폴리오가 한 섹터로 몰리는 것을 완화한다.
- 시장 전체 rank와 섹터 내 rank를 모두 피처로 넣어 모델이 선택하게 한다.
- 섹터별 최대 편입 종목 수 또는 최대 비중 제한에 쓴다.

주의:

- 섹터 내 종목 수가 너무 적으면 z-score가 불안정하다.
- 섹터 정보가 없는 종목은 별도 그룹으로 두거나 제외한다.
- 섹터 중립화는 알파를 줄일 수도 있다. 강한 섹터 트렌드 자체가 신호일 수 있기 때문이다.

권장 정책:

```text
MP_CORE에서는 섹터 효과를 완전히 제거하지 않는다.
market rank, sector rank, sector z-score를 모두 저장하고
최종 편입 단계에서 섹터 최대 비중만 제한한다.
```

## 5. 밸류와 퀄리티의 관계

원문은 밸류와 퀄리티가 종종 반대 관계에 있다고 설명한다. 싸게 거래되는 기업은 우량성이 낮은 경우가 많고, 우량한 기업은 이미 비싼 가격에 거래되는 경우가 많다.

핵심 구도:

| 구간 | 의미 | 투자 매력 |
|---|---|---|
| 낮은 가격 + 낮은 퀄리티 | 전형적 저평가/위험주 | 선별 필요 |
| 높은 가격 + 낮은 퀄리티 | 비싸고 나쁜 종목 | 피해야 함 |
| 높은 가격 + 높은 퀄리티 | 우량 성장주 | 가격 부담 |
| 낮은 가격 + 높은 퀄리티 | 좋은 회사를 싸게 사는 구간 | 목표 |

원문은 PBR과 GPA의 관계를 보고, PBR이 낮은 그룹일수록 GPA도 낮은 경향을 확인한다.

### MP_CORE_LATER 적용

이 내용은 재무 데이터가 안정화된 뒤 유용하다.

피처 후보:

```text
value_score
quality_score
value_quality_spread
cheap_quality_score
sector_neutral_value
sector_neutral_quality
```

해석:

- value만 높으면 가치 함정일 수 있다.
- quality만 높으면 이미 비쌀 수 있다.
- value와 quality가 동시에 좋은 종목은 장기 포트폴리오 후보가 된다.

현재 `MP_CORE` 1차에서는 보류하고, v2 또는 별도 QVM 전략에서 쓰는 것이 맞다.

## 6. 마법공식

마법공식은 조엘 그린블라트가 소개한 밸류+퀄리티 결합 전략이다.

구성:

| 팩터 | 원래 지표 | 대략적 의미 |
|---|---|---|
| Value | Earnings Yield | 기업가치 대비 이익이 높을수록 좋음 |
| Quality | Return on Capital | 투하자본 대비 이익이 높을수록 좋음 |

원문 계산:

```text
Earnings Yield = EBIT / Enterprise Value
Enterprise Value = Market Cap + Net Debt
Return on Capital = EBIT / Invested Capital
```

원문은 두 지표의 rank를 각각 구한 뒤 rank 합이 좋은 상위 30종목을 고른다.

### MP_CORE 판단

마법공식은 좋은 전략이지만, 현재 `MP_CORE`에 직접 섞기보다는 `NEXT_MODEL`로 분리하는 편이 낫다.

이유:

- 필요한 재무제표 항목이 많다.
- 발표 시점 통제가 중요하다.
- 장기 보유/연간 리밸런싱 성격이 강하다.
- 현재 `MP_CORE`의 가격/수급/단중기 예측 모델과 시간축이 다르다.

다음 모델 후보:

```text
MP_MAGIC_FORMULA
- EBIT / Enterprise Value
- EBIT / Invested Capital
- rank z-score 결합
- 분기 또는 연간 리밸런싱
- 금융업 별도 처리
```

필요 데이터:

- 지배주주순이익
- 법인세비용
- 이자비용
- 시가총액
- 총부채
- 현금 및 현금성자산
- 유동자산/유동부채
- 비유동자산
- 감가상각비

## 7. 이상치 처리

원문은 이상치 처리 방법으로 트림과 윈저라이징을 설명한다.

| 방법 | 설명 | 장점 | 단점 |
|---|---|---|---|
| Trim | 상하위 극단 데이터를 제거 | 강한 이상치 제거 | 표본 손실 |
| Winsorizing | 상하위 극단값을 분위수 경계값으로 대체 | 표본 유지 | 경계값에 데이터가 몰림 |

예:

```text
상위 99% 초과 값 -> 99% 값으로 대체
하위 1% 미만 값 -> 1% 값으로 대체
```

### MP_CORE_NOW 적용

이상치 처리는 현재 모델에 바로 필요하다.

적용 후보:

```text
daily_return
ret_20d
ret_60d
ret_252d
vol_60d
trade_amount
foreign_net_buy_amount
institution_net_buy_amount
value ratios
quality ratios
```

권장 정책:

| 데이터 | 처리 |
|---|---|
| 일간 수익률 | raw 유지 + 모델용 winsorized 생성 |
| 거래대금 | log transform 우선, 필요 시 winsorizing |
| PER/PBR/PCR/PSR | 음수/Inf/결측 처리 후 winsorizing |
| 재무비율 | 업종별 winsorizing 검토 |
| 차트 표시 | clipped display value 별도 |

중요한 구분:

```text
raw_value: 원천값
model_value: 모델 학습용 전처리값
display_value: 차트 표시용 값
```

## 8. 팩터 결합 방법

원문은 단순 rank 합의 한계를 지적한다. 각 팩터별 결측치 개수가 다르면 rank 범위가 달라지고, 그 상태에서 가중합을 하면 의도하지 않은 왜곡이 생긴다.

원문 권장 방식:

```text
1. 각 팩터를 좋은 방향으로 rank 한다.
2. rank를 z-score로 정규화한다.
3. 정규화된 값을 가중합한다.
```

공식:

```text
combined_score =
  weight_a * zscore(rank(factor_a)) +
  weight_b * zscore(rank(factor_b)) +
  ...
```

### MP_CORE_NOW 적용

이 내용은 현재 모델 설계에 중요하다.

피처 결합 예:

```text
momentum_score =
  0.4 * z(rank(ret_20d)) +
  0.3 * z(rank(ret_60d)) +
  0.3 * z(rank(ret_120d))

risk_score =
  0.5 * z(rank_low(vol_60d)) +
  0.3 * z(rank_low(beta_252d)) +
  0.2 * z(rank_high(liquidity))
```

주의:

- rank 방향을 명확히 해야 한다. 수익률은 높을수록 좋고, 변동성은 낮을수록 좋다.
- z-score는 결측이 있는 종목을 어떻게 처리할지 먼저 정해야 한다.
- 팩터 가중치는 백테스트로 과최적화되기 쉽다.
- 학습 모델을 쓸 경우에도 raw feature와 rank-normalized feature를 모두 비교할 가치가 있다.

## 9. QVM 멀티팩터 포트폴리오

원문은 Quality, Value, Momentum을 결합한 QVM 포트폴리오를 만든다.

구성:

| 팩터 | 지표 |
|---|---|
| Quality | ROE, GPA, CFO |
| Value | PER, PBR, PSR, PCR |
| Momentum | 3개월, 6개월, 12개월 수익률 |

절차:

1. 각 팩터 내부 지표를 계산한다.
2. 지표별 rank를 구한다.
3. rank를 z-score로 정규화한다.
4. 팩터 내부 점수를 만든다.
5. Quality, Value, Momentum 점수 간 상관관계를 확인한다.
6. 세 팩터 점수를 다시 정규화해 동일 비중 또는 사용자 지정 비중으로 합친다.
7. 상위 종목을 선택한다.

### MP_CORE_LATER / NEXT_MODEL 판단

QVM은 강력한 구조지만, 현재 `MP_CORE` 1차 모델에는 일부만 쓰는 것이 맞다.

현재 반영:

- Momentum 부분은 바로 사용
- rank z-score 결합 방식은 바로 사용
- 섹터 중립 rank도 함께 사용

나중 반영:

- Quality와 Value는 재무 데이터 파이프라인 이후
- QVM 자체는 별도 `MP_QVM` 전략으로 분리

다음 모델 후보:

```text
MP_QVM
- Quality: ROE/GPA/CFO
- Value: PER/PBR/PCR/PSR
- Momentum: 3/6/12M return
- factor weight: 1/3 each by default
- sector neutral rank option
- quarterly/monthly rebalance 비교
```

## 12. 한 줄 요약

이 장은 "좋은 팩터를 찾는 것"보다 "팩터를 안전하게 결합하는 방법"이 핵심이다. 현재 `MP_CORE`에는 섹터 중립, 이상치 처리, rank z-score 정규화를 바로 넣고, 마법공식과 QVM은 재무 데이터가 준비된 뒤 별도 모델로 분리하는 것이 맞다.
