## 1. 머신러닝 기초

### 학습 유형 분류

| 유형 | 특징 | 대표 알고리즘 |
|------|------|--------------|
| 지도 학습 | 입력값 + 정답 레이블로 학습 | Penalized Regression, 결정 트리, 랜덤 포레스트, 나이브 베이즈 |
| 비지도 학습 | 입력값만으로 패턴 학습 | PCA, k-평균 군집 |
| 강화 학습 | 보상 최대화를 위해 스스로 학습 | 알파고 |

### 과적합(Overfitting) 방지

> "백테스팅에서는 잘 나오는데 실제 수익률은 안 나온다" = 과적합

**대응책**:
- **Train/Test 분리**: 전체 데이터의 20~25%를 test data로 분리. 모델 학습에 미사용.
- **Cross-Validation**: training data를 k개 서브셋으로 분할 → k번 순환 검증

## 2. 결정 트리 (Decision Tree)

### 개념

나무 형태의 판단 규칙 조합으로 데이터를 학습하고 예측하는 알고리즘. 일종의 "스무고개".

예) Fwd P/E ≤ 8.815? → VKOSPI ≤ 14.885? → 클래스 판단

### 훈련 알고리즘: 지니 불순도(Gini Impurity)

```
지니 불순도 Gi = 1 - Σ(pik)²
                    k=1~n
```

- `pik`: i번째 노드에서 클래스 k에 속한 샘플의 비율
- 값이 0에 가까울수록 순수 (한 클래스만 존재)
- 모든 특성·임계값을 탐색하여 불순도를 가장 크게 낮추는 분할 기준 선택

**예시**: samples=3264, up=1346, neutral=721, down=1197  
→ Gi = 1 - (1346/3264)² - (721/3264)² - (1197/3264)² = **0.647**

첫 분할(fwd_pe ≤ 8.815) 후 종합 불순도: **0.607** (개선됨)

### 하이퍼파라미터

| 파라미터 | 설명 |
|---------|------|
| `criterion` | 불순도 계산 함수 (gini or entropy) |
| `max_depth` | 트리 최대 깊이 |
| `max_leaf_nodes` | leaf node 최대 개수 |

### 결정 트리의 단점

충분한 깊이가 주어지면 training data에 100% 일치하는 모델 가능 → **과적합 위험**.  
실무에서는 단독 사용보다 랜덤 포레스트의 하위 구성요소로 사용.

## 3. 랜덤 포레스트 (Random Forest)

### 앙상블 기법

| 기법 | 설명 |
|------|------|
| 배깅(Bagging) | training data에서 중복 허용 샘플링 → 여러 모델 → 평균 예측 |
| 페이스팅 | 중복 없는 샘플링 방식 |
| 부스팅(AdaBoost) | 잘못 분류된 샘플의 가중치를 높여 순차적 학습 |

### 랜덤 포레스트

**결정 트리 + 배깅** = 수십~수백 개의 결정 트리를 만들어 종합 판단.

- 각 트리마다 피처 개수도 랜덤하게 줄여 다양성 강화
- **장점**: 앙상블로 overfitting 감소, 예측력 향상
- **단점**: 블랙박스 구조 (내부 판단 직관적 이해 어려움)

### 파이썬 코드

```python
from sklearn.ensemble import RandomForestClassifier

rnd_clf = RandomForestClassifier(
    n_estimators=100,    # 결정 트리 개수
    max_leaf_nodes=40,   # 각 트리의 leaf node 최대 개수
    max_features=8,      # 각 트리에 사용되는 피처 수 상한
    n_jobs=-1            # 병렬 처리
)
rnd_clf.fit(X_train, y_train)
y_pred = rnd_clf.predict(X_new)
```

## 4. 분류 성능 지표

### 혼동행렬(Confusion Matrix)

|  | 실제 Positive | 실제 Negative |
|--|---------------|---------------|
| 예측 Positive | TP (맞춤) | FP (오탐) |
| 예측 Negative | FN (누락) | TN (맞춤) |

### 주요 지표 수식

```
정확도(Accuracy)  = (TP + TN) / (TP + TN + FP + FN)
정밀도(Precision) = TP / (TP + FP)
재현율(Recall)    = TP / (TP + FN)
F1 Score          = 2 / (1/정밀도 + 1/재현율)  ← 정밀도·재현율의 조화평균
```

> 정밀도 ↑ ↔ 재현율 ↓ (trade-off 관계)

### K-fold 교차 검증

```python
from sklearn.model_selection import cross_val_score

scores = cross_val_score(rnd_clf, X_train, y_train, scoring="accuracy", cv=10)
print(scores.mean())
```

k=10으로 전체 데이터를 10등분 → 10번 순환 검증 → 평균 성능 확인
