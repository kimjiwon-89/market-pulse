## 1. 단순 선형 회귀분석

독립변수(x)와 종속변수(y)의 **선형관계**를 추정하는 가장 기본 모델.  
Ridge, LASSO, 로짓 등 고급 기법의 이론적 기초.

### 모델식

```
y = β0 + β1·x + u
```

- y: 종속변수, x: 독립변수, u: 오차항
- β1: 기울기 모수(베타), β0: 절편 모수

### OLS 추정량 (보통최소제곱법)

오차항 제곱합 `Σu²` 을 최소화하는 β0, β1 추정.

```
β1_hat = cov(x,y) / var(x) = Σ(xi-x̄)(yi-ȳ) / Σ(xi-x̄)²
β0_hat = ȳ - β1_hat · x̄
```

### 모델 유의성 지표

| 지표 | 정의 | 범위 |
|------|------|------|
| 상관계수 r | cov(x,y) / (sx·sy) | -1 ~ 1 |
| 결정계수 R² | SSE/SST = 1 - SSR/SST | 0 ~ 1 |

- 단순회귀에서 `R² = r²`
- SST = SSE + SSR
  - SST(총제곱합): Σ(yi-ȳ)²
  - SSE(설명된 제곱합): Σ(ŷi-ȳ)²
  - SSR(잔차 제곱합): Σ(yi-ŷi)²

> **상관계수 vs 베타 구분**: 상관계수는 선형관계 강도, 베타는 y의 x에 대한 민감도(단위 보존).

## 2. 다중 회귀분석

독립변수가 k개인 회귀 모델.

```
y = β0 + β1·x1 + β2·x2 + ... + βk·xk + u
```

βi: xi가 1단위 변화할 때 y의 변화량 (다른 변수 고정 시)

### 행렬 표현 (OLS 추정)

```
β_hat = (X'X)^(-1) · X'y
```

### 주의사항

1. **수정결정계수 R²_bar 사용**: 독립변수 추가 시 R²는 기계적으로 증가 → 패널티 반영
   ```
   R²_bar = 1 - [SSR/(n-k-1)] / [SST/(n-1)]
   ```

2. **다중공선성(Multicollinearity)**: 독립변수 간 높은 상관 → OLS 추정량 분산 급증 → 불안정한 계수

### 실전 예제: SK 주가 vs WTI 유가

- 샘플: 2016~2020년 월간 수익률 60개
- 추정 결과: `[SK 월수익률] = 0.34 + 0.49 × [WTI 월수익률] + u`
- 해석: WTI 1% 상승 시 SK 주가 0.49% 상승 (유가 베타 = 0.49)

### 파이썬 코드

```python
from sklearn.linear_model import LinearRegression

# 단순 회귀
lr = LinearRegression()
lr.fit(x_rm, y)
print(lr.coef_)       # 기울기
print(lr.intercept_)  # 절편
print(lr.score(x_rm, y))  # R²

# 다중 회귀
lr2 = LinearRegression()
lr2.fit(X, y)  # X: (n × k) 행렬
print(lr2.score(X, y))  # R² ≈ 0.74
```

### 엑셀 함수

```
slope(y_range, x_range)      → 기울기 β1
intercept(y_range, x_range)  → 절편 β0
correl(array1, array2)        → 상관계수 r
linest(y, X, TRUE, TRUE)      → 다중회귀 전체 결과 (배열수식: Ctrl+Shift+Enter)
```

## 3. 벌점 회귀분석 (Penalized / Regularized Regression)

회귀계수 축소로 **과적합(Overfitting) 방지**. 독립변수 多 + 샘플 少인 현실 데이터에 유효.

### 과적합이란?

학습 데이터에만 완벽히 맞고 미래 예측력은 떨어지는 현상.  
"백테스팅에서는 잘 나오는데 실제 수익률은 안 나온다"

### 3.1 Ridge 회귀 (L2 정규화)

```
목적함수: Σ(yi - ŷi)² + λ·Σβj²  →  최소화하는 β 찾기
```

- 패널티 항목: 회귀계수 **제곱합** (L2 norm)
- 닫힌 해 존재: `β_Ridge = (X'X + λI)^(-1) · X'y`
- λ→0: OLS와 동일 / λ→∞: 모든 계수 → 0
- 특징: 계수들이 전반적으로 축소되지만 **0이 되지는 않음**

### 3.2 LASSO 회귀 (L1 정규화)

```
목적함수: Σ(yi - ŷi)² + λ·Σ|βj|  →  최소화하는 β 찾기
```

- 패널티 항목: 회귀계수 **절대값 합** (L1 norm)
- 특징: 일부 계수를 **정확히 0으로** 만들어 **변수 선택** 기능
- 닫힌 해 없음 (컴퓨터로 수치 계산)
- λ 상승 시 계수들이 **순차적으로** 0에 도달

### 3.3 Elastic Net

```
목적함수: Σ(yi - ŷi)² + λ1·Σ|βj| + λ2·Σβj²  →  최소화
```

- LASSO(L1) + Ridge(L2) 패널티 동시 적용 ("짬짜면")
- λ1, λ2 조절로 두 방식의 강조 정도 균형

### Ridge vs LASSO 비교

| 항목 | Ridge | LASSO |
|------|-------|-------|
| 패널티 | L2 (제곱합) | L1 (절대값) |
| 변수 선택 | ❌ (0에 가깝게만) | ✅ (정확히 0) |
| 닫힌 해 | ✅ | ❌ |
| 적합 상황 | 모든 변수 중요 | 변수 축소 필요 |

### 하이퍼파라미터 λ 결정: 교차 검증(Cross-Validation)

머신러닝에서는 training/test data 분리 후 K-fold 교차 검증으로 λ 튜닝.

### 실전 예제: POSCO 주가 모델

- 독립변수: KOSPI, 원/달러, 원/엔, WTI 수익률
- OLS 결과: 원/엔 회귀계수 0.01 → 유의미한지 의심
- LASSO(λ=0.0001): 원/엔 계수 → **0** (자동 변수 제거)
- LASSO(λ=0.0005): 환율 변수 전부 제거 → `posco = 0.69·kospi + 0.05·wti`

### 파이썬 코드

```python
from sklearn.linear_model import Ridge, Lasso, ElasticNet

# Ridge
ridge = Ridge(alpha=1.0)  # alpha = λ
ridge.fit(X, y)
print(ridge.coef_)

# LASSO
lasso = Lasso(alpha=0.0001)
lasso.fit(X, y)
print(lasso.coef_)  # 일부 계수 = 0.0

# Elastic Net
enet = ElasticNet()
enet.fit(X, y)
print(enet.coef_)
```

## 4. 투자 활용 요약

| 상황 | 추천 모델 |
|------|-----------|
| 독립변수 2~5개, 경제적 관계 명확 | OLS 다중회귀 |
| 독립변수 많고 일부만 유효할 것 같을 때 | LASSO |
| 모든 변수가 어느 정도 기여, 다중공선성 우려 | Ridge |
| 변수 선택 + 다중공선성 모두 고려 | Elastic Net |
| 종속변수가 확률/이분 데이터 | 로짓 모델 |
