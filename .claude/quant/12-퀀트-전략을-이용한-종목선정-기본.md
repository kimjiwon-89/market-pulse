## 1. 이 문서를 읽는 기준

이 장은 베타, 저변동성, 모멘텀, 밸류, 퀄리티 같은 대표 팩터로 종목을 고르는 방법을 다룬다.

다만 현재 Market Pulse의 중심 모델은 `MP_CORE`다. `MP_CORE`는 여러 전통 팩터 전략을 각각 독립 실행하는 모델이라기보다, 가격/수급/유동성/리스크/일부 재무 피처를 모아 다음 기간 기대 방향을 판단하는 단일 코어 모델이다.

따라서 이 문서는 아래 기준으로 분리한다.

| 분류 | 의미 | 처리 |
|---|---|---|
| `MP_CORE 직접 반영` | 현재 모델 입력 피처 또는 리스크 필터로 바로 쓸 수 있음 | 우선 구현 후보 |
| `MP_CORE 보조 진단` | 단독 전략은 아니지만 모델 결과 해석에 도움 | diagnostics 화면 후보 |
| `다음 모델 후보` | 지금 모델 주제와는 다소 분리됨 | 별도 전략/모델로 보관 |

## 2. 글의 핵심

퀀트 투자는 크게 포트폴리오 운용 전략과 트레이딩 전략으로 나뉜다. 원문은 포트폴리오 운용 전략 관점에서, 검증된 팩터를 기준으로 좋은 종목을 고르는 방법을 설명한다.

핵심 팩터:

- Beta: 시장 민감도
- Low volatility: 수익률 변동성이 낮은 종목
- Momentum: 최근 수익률 또는 위험조정 수익률이 높은 종목
- Value: PER/PBR/PCR/PSR이 낮은 종목
- Quality: ROE, GPA, CFO, F-Score가 높은 종목

Market Pulse 관점의 핵심은 다음과 같다.

- 모멘텀, 변동성, 베타는 현재 가격 데이터만으로 계산 가능하므로 `MP_CORE` 1차 피처에 적합하다.
- 밸류와 퀄리티는 재무제표와 가치지표 데이터가 안정적으로 들어온 뒤 2차 피처로 넣는 것이 맞다.
- 원문의 상위 30종목 단순 선별 방식은 좋은 학습 예제지만, 실전 모델에서는 거래대금, 시총, 섹터 편중, 비용, 리밸런싱 주기를 함께 통제해야 한다.
- 각 팩터는 단독 전략으로도 쓸 수 있지만, 현재 목표에서는 `MP_CORE`의 입력 변수와 비교 벤치마크로 먼저 쓰는 것이 안전하다.

## 3. 모델별 분류

| 원문 주제 | MP_CORE 반영 | 다음 모델 후보 | 판단 |
|---|---|---|---|
| 베타 | 리스크 피처, 시장 민감도 필터 | `MP_LOW_BETA` | 현재 모델의 위험 조절 변수로 우선 사용 |
| 저변동성 | 핵심 리스크 피처 | `MP_LOW_VOL` | 현재 모델과 잘 맞음 |
| 12개월 모멘텀 | 핵심 가격 피처 | `MP_MOMENTUM` | 현재 모델과 잘 맞음 |
| 위험조정 모멘텀 | 핵심 가격+리스크 피처 | `MP_RISK_ADJ_MOM` | 현재 모델과 매우 잘 맞음 |
| 저PBR/멀티밸류 | 보조 재무 피처 | `MP_VALUE` | 재무 데이터 안정화 전까지 보류 |
| F-Score | 보조 퀄리티 피처 | `MP_PIOTROSKI` | DART/재무제표 파이프라인 이후 |
| ROE/GPA/CFO 퀄리티 | 보조 퀄리티 피처 | `MP_QUALITY` | 2차 확장 |

현재 우선순위:

1. `MP_CORE`: 모멘텀 + 위험조정 모멘텀 + 변동성 + 베타 + 유동성
2. `MP_CORE v2`: 밸류 + 퀄리티 피처 추가
3. 다음 모델: 저변동성/밸류/퀄리티 단독 전략을 비교 벤치마크로 분리

## 4. 베타

베타는 개별 종목 수익률이 시장 수익률에 얼마나 민감하게 반응하는지 나타내는 값이다.

개념:

```text
stock_return = alpha + beta * market_return
```

해석:

| beta | 의미 |
|---:|---|
| 0.5 | 시장보다 덜 움직이는 방어적 종목 |
| 1.0 | 시장과 비슷하게 움직이는 종목 |
| 1.5 | 시장보다 크게 움직이는 공격적 종목 |

원문은 KOSPI 200 ETF와 개별 증권주의 일간 수익률을 구한 뒤, 선형회귀의 기울기로 베타를 계산한다.

### MP_CORE 적용

베타는 단독 매수 신호보다 리스크 조절 피처로 쓰는 편이 맞다.

피처 후보:

```text
beta_60d
beta_120d
beta_252d
market_corr_252d
alpha_252d
r_squared_252d
```

활용:

- 시장 하락 구간에서 고베타 종목 비중을 줄인다.
- 같은 모멘텀 점수라면 베타가 과도하게 높은 종목을 감점한다.
- 코스피/코스닥 별 benchmark를 분리해 베타를 계산한다.
- 회귀 설명력이 낮은 종목은 베타 신뢰도를 낮게 본다.

주의:

- 베타는 기간에 따라 크게 바뀐다.
- 신규상장/거래정지 종목은 회귀 표본이 부족하다.
- 시장 전체 급락 구간에서는 상관관계가 평소보다 높아질 수 있다.

## 5. 저변동성 전략

원문은 최근 1년 일간 수익률의 표준편차를 계산한 뒤 연율화하고, 변동성이 낮은 30종목을 선택한다. 주간 기준에서는 일간 수익률을 주간 누적 수익률로 바꾼 뒤 표준편차를 계산한다.

계산:

```text
daily_vol_252d = std(daily_return over last 252 days) * sqrt(252)
weekly_vol_52w = std(weekly_return over last 52 weeks) * sqrt(52)
```

원문의 핵심은 변동성이 큰 종목이 항상 높은 보상을 주지는 않으며, 오히려 저변동성 종목이 더 좋은 성과를 낼 수 있다는 저변동성 효과다.

### MP_CORE 직접 반영

저변동성은 현재 모델과 잘 맞는다.

피처 후보:

```text
vol_20d
vol_60d
vol_120d
vol_252d
downside_vol_60d
vol_rank_in_market
vol_rank_in_sector
```

활용:

- 과도한 변동성 종목 제외 필터
- 기대수익 점수를 변동성으로 조정
- 동일 신호 내 포지션 비중 조절
- 손실 구간에서 방어적 종목 선호

다음 모델 후보:

```text
MP_LOW_VOL
- 최근 12개월 변동성 하위 N종목
- 거래대금/시총 필터
- 월간 리밸런싱
- 동일가중 또는 inverse volatility 가중
```

## 6. 모멘텀 전략

원문은 최근 1년 누적수익률이 높은 30종목을 고르는 12개월 모멘텀을 설명한다. 이어서 단순 누적수익률을 변동성으로 나눈 위험조정 수익률 기준으로도 종목을 고른다.

계산:

```text
momentum_12m = product(1 + daily_return over last 252 days) - 1
risk_adj_momentum_12m = momentum_12m / vol_252d
```

원문의 중요한 판단은 단순 수익률만 보면 테마 급등주가 섞일 수 있으므로, 변동성을 함께 고려해야 한다는 점이다.

### MP_CORE 직접 반영

모멘텀은 `MP_CORE`의 핵심 가격 피처다.

피처 후보:

```text
ret_5d
ret_20d
ret_60d
ret_120d
ret_252d
ret_20d_ex_recent_5d
risk_adj_ret_60d
risk_adj_ret_252d
momentum_rank_market
momentum_rank_sector
```

중요한 설계:

- 단기 과열을 피하려면 최근 며칠 수익률을 제외한 모멘텀도 본다.
- 12개월 모멘텀은 중기 전략에 가깝다. 단기 예측 모델에서는 20일/60일도 중요하다.
- 거래대금이 낮은 종목의 모멘텀은 체결 가능성이 낮다.
- 리밸런싱 기준일 이전 데이터만 사용해야 한다.

다음 모델 후보:

```text
MP_MOMENTUM
- 3/6/12개월 모멘텀 점수
- 최근 1개월 reversal 구간 제외
- 월간 리밸런싱

MP_RISK_ADJ_MOM
- 누적수익률 / 변동성
- 변동성 상한 필터
- 섹터별 상위 종목 제한
```

## 7. 밸류 전략

원문은 저PBR 포트폴리오와 PER/PBR/PCR/PSR 네 지표를 결합한 멀티 밸류 포트폴리오를 설명한다.

핵심:

- 낮은 PER: 이익 대비 저평가
- 낮은 PBR: 순자산 대비 저평가
- 낮은 PCR: 현금흐름 대비 저평가
- 낮은 PSR: 매출 대비 저평가

원문은 각 가치지표를 낮은 순서대로 순위화하고, 네 지표의 순위 합이 낮은 종목을 고른다. 지표 간 상관관계를 확인한 뒤, 상관이 낮은 지표를 함께 쓰면 분산효과를 기대할 수 있다고 설명한다.

### MP_CORE 판단

밸류는 좋은 피처지만 현재 `MP_CORE` 1차 구현의 중심은 아니다.

이유:

- 안정적인 재무제표/가치지표 데이터가 먼저 필요하다.
- 과거 시점의 밸류를 계산하려면 당시 가격과 당시 사용 가능했던 재무제표가 필요하다.
- 현재 시점 PER/PBR을 과거 백테스트에 넣으면 look-ahead bias가 생긴다.

따라서 지금은 `다음 모델 후보` 또는 `MP_CORE v2 보조 피처`로 둔다.

피처 후보:

```text
per_rank
pbr_rank
pcr_rank
psr_rank
value_composite_rank
value_rank_in_sector
```

다음 모델 후보:

```text
MP_VALUE
- PER/PBR/PCR/PSR rank sum
- 음수/결측 지표 제외
- 섹터 중립 rank
- 분기 또는 월간 리밸런싱
```

## 8. 퀄리티 전략

원문은 퀄리티를 수익성, 이익 안정성, 재무구조, 성장성, 회계 품질, 배당/희석, 투자 효율 등으로 설명한다.

대표 예시는 Piotroski F-Score다.

F-Score 구성:

| 구분 | 지표 | 좋은 조건 |
|---|---|---|
| 수익성 | ROA | 양수 |
| 수익성 | CFO | 양수 |
| 수익성 | ROA 변화 | 전년 대비 증가 |
| 수익성 | ACCRUAL | CFO > ROA |
| 재무성과 | Leverage | 전년 대비 감소 |
| 재무성과 | Liquidity | 전년 대비 증가 |
| 재무성과 | Equity offer | 유상증자 없음 |
| 운영효율 | Margin | 전년 대비 증가 |
| 운영효율 | Turnover | 전년 대비 증가 |

원문은 각 조건을 만족하면 1점, 아니면 0점으로 계산해 0~9점의 F-Score를 만든다. 또한 ROE, GPA, CFO를 각각 순위화한 뒤 순위 합이 낮은 종목을 퀄리티 우수 종목으로 고른다.

### MP_CORE 판단

퀄리티는 좋은 보조 피처지만 재무 데이터 파이프라인 이후에 넣어야 한다.

피처 후보:

```text
roe
gpa = gross_profit / total_assets
cfo_to_assets
f_score
leverage_change
liquidity_change
margin_change
turnover_change
```

주의:

- 1~4월에는 전년도 재무제표가 모두 확정되지 않을 수 있다.
- 금융업은 일반 제조업과 재무제표 구조가 다르다.
- 재무제표 발표일 기준으로 사용 가능 시점을 통제해야 한다.
- F-Score는 저평가주 안에서 우량주를 고르는 데 특히 잘 맞는다.

다음 모델 후보:

```text
MP_PIOTROSKI
- 저PBR universe
- F-Score 8~9점 우선
- 분기 리밸런싱

MP_QUALITY
- ROE/GPA/CFO rank sum
- 섹터 중립
- value 또는 momentum과 결합
```

## 10. 구현 메모

현재 프로젝트의 `market_daily_price`만으로 바로 가능한 것:

- 일간 수익률 계산
- 20/60/120/252일 누적수익률
- 연율화 변동성
- 위험조정 수익률
- KOSPI/KOSDAQ benchmark 대비 beta
- 거래대금 기반 유동성 필터

추가 데이터가 필요한 것:

- PER/PBR/PCR/PSR: 가치지표 데이터
- ROE/GPA/CFO: 재무제표 데이터
- F-Score: 최소 2개년 이상 재무제표와 발행주식수/유상증자 정보

권장 feature snapshot:

```sql
CREATE TABLE quant_feature_snapshot (
    base_date DATE NOT NULL,
    asset_code VARCHAR(20) NOT NULL,
    ret_20d NUMERIC(18, 8),
    ret_60d NUMERIC(18, 8),
    ret_120d NUMERIC(18, 8),
    ret_252d NUMERIC(18, 8),
    vol_60d NUMERIC(18, 8),
    vol_252d NUMERIC(18, 8),
    risk_adj_ret_252d NUMERIC(18, 8),
    beta_252d NUMERIC(18, 8),
    liquidity_rank INTEGER,
    momentum_rank INTEGER,
    volatility_rank INTEGER,
    value_rank INTEGER,
    quality_rank INTEGER,
    created_at TIMESTAMP DEFAULT NOW(),
    PRIMARY KEY (base_date, asset_code)
);
```

## 11. 헷갈리지 않기 위한 운영 원칙

앞으로 외부 자료를 계속 넣을 때는 아래처럼 분류한다.

1. `MP_CORE_NOW`: 지금 모델에 바로 쓰는 데이터/피처/검증법
2. `MP_CORE_LATER`: 현재 모델과 관련 있지만 데이터가 아직 부족한 것
3. `NEXT_MODEL`: 별도 전략으로 분리할 아이디어
4. `REFERENCE_ONLY`: 배경지식 또는 구현 우선순위 낮은 내용

이 기준을 문서마다 넣으면 자료가 많아져도 모델 방향은 흐려지지 않는다.

## 12. 한 줄 요약

이 장은 베타·저변동성·모멘텀·밸류·퀄리티라는 기본 팩터의 종목선정법을 보여주지만, 현재는 모멘텀/변동성/베타를 `MP_CORE` 핵심 피처로 우선 쓰고, 밸류/퀄리티/F-Score는 재무 데이터 구축 후 다음 모델 또는 v2 피처로 넘기는 것이 맞다.
