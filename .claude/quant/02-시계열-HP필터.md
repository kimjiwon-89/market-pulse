# 퀀트 모델링 (2): HP 필터 (Hodrick-Prescott Filter)

> 출처: 삼성증권 퀀트 모델링 A to Z (2) HP 필터 (2021.4.7)

---

## 1. HP 필터란?

HP 필터(Hodrick-Prescott 필터)는 거시경제 시계열 데이터에서 **장기 추세(Trend)**와 **단기 순환(Cyclical)**을 기술적으로 분리하는 기법.

- 경제학적 이론 기반 모델이 아니라, 통계적 특성만으로 추세/순환을 추출
- 이동평균법도 필터의 일종 — HP 필터는 그보다 고도화된 비선형 필터

### 분해 구조

```
yt = τt + ct + et
```

- `yt`: 원 시계열
- `τt`: 장기 추세 (HP 필터 출력값)
- `ct`: 순환 변동 (원데이터 - 추세)
- `et`: 오차항

---

## 2. HP 필터 수식

```
min_τ [ Σ(yt - τt)² + λ · Σ[(τt+1 - τt) - (τt - τt-1)]² ]
         t=1~T              t=2~T-1
```

- **왼쪽 항**: τt가 yt를 닮아야 한다 (추세가 원데이터에서 너무 벗어나지 않을 것)
- **오른쪽 항**: τt의 움직임이 매 시점마다 부드러워야 한다 (2차 차분이 작을 것)
- **λ**: 두 항 사이의 가중치 = 평활화 계수

### λ 값 해석

| λ 값 | 효과 |
|------|------|
| λ → 0 | 추세 = 원 시계열 (평활화 없음) |
| λ → ∞ | 추세 = 직선 (완전 평탄화) |

---

## 3. 평활화 계수 λ 관행값

| 데이터 주기 | 권장 λ |
|------------|--------|
| 연간 | 100 (Ravn & Uhlig 2002는 6.25 권장) |
| 분기 | 1,600 |
| 월별 | 14,400 |

> 데이터 빈도가 높을수록 큰 λ 사용 → 트렌드가 부드럽게 움직이도록 제어

- 구조 변화에 민감한 추세가 필요하면 λ를 낮추는 것이 적절

### HP 필터 특성 주의사항

새로운 데이터가 추가되면 **전체 출력값이 조금씩 바뀐다** (양방향 평탄화 특성).  
최근 시점의 추세값은 향후 데이터가 들어오면 소급 수정됨.

---

## 4. 실전 예제: 한국 잠재성장률 추정

한국 1960~2020년 연간 실질 GDP에 HP 필터(λ=100) 적용:

- HP 필터 추세 = **잠재 GDP** 추정치
- 추세의 연도별 성장률 = **잠재성장률** proxy
- 최근 값: **2.3%** → "현재 한국 잠재성장률은 약 2.3%"

GDP gap / output gap 계산:
```
GDP gap = yt - τt  (실제 GDP - 잠재 GDP)
```

---

## 5. 사용법

### 엑셀 사용법

엑셀 기본 기능에는 HP 필터 없음 → 외부 추가기능 필요:

```
HP(data, lambda):  배열수식 [Ctrl+Shift+Enter]로 입력
  → 원데이터와 동일 크기의 추세 데이터 반환
```

### 파이썬 코드

```python
import pandas as pd
import statsmodels.api as sm
import matplotlib.pyplot as plt

# 실질 GDP 샘플 데이터 로드
realgdp = sm.datasets.macrodata.load_pandas().data['realgdp']
realgdp.index = pd.period_range('1959Q1', '2009Q3', freq='Q')

# HP 필터 실행 (λ=1600, 분기 데이터)
cycle, trend = sm.tsa.filters.hpfilter(realgdp, 1600)

# 결과
# trend: 추세 데이터 (잠재 GDP)
# cycle: 순환 데이터 = 원데이터 - 추세 (GDP gap)

# 시각화
realgdp.loc['2003-03-31':].plot()
trend.loc['2003-03-31':].plot()
plt.show()
```

## 6. 투자 활용 요약

| 활용 목적 | 방법 |
|-----------|------|
| 잠재성장률 추정 | GDP에 HP 필터 적용, 추세의 성장률 계산 |
| GDP gap 파악 | 실제 GDP - HP 추세 |
| 금리/물가 사이클 분석 | 거시 시계열에 HP 필터 적용, 순환 주기 확인 |
| 주가 장기 추세 vs 단기 변동 | 주가 지수에 HP 필터 적용 |

> **핵심**: HP 필터는 경제 이론 없이도 "장기 추세"를 기계적으로 뽑아낼 수 있는 도구.  
> 잠재성장률, 아웃풋 갭 등 거시 분석에서 표준적으로 사용된다.
