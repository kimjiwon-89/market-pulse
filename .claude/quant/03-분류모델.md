## 1. 로짓 모델 (Logistic Regression)

### 왜 필요한가?

선형 회귀분석의 적합치(ŷ)는 [0,1] 범위를 벗어날 수 있다.  
종속변수가 **이분적 데이터(0 or 1)** 또는 **확률 데이터**일 때 로짓 모델이 유용.

예) 미국 대통령 선거에서 공화당이 더 많은 표를 얻을 확률 추정 (Fair, 1996)

### 모델 수식

```
zi = β0 + β1·x1i + β2·x2i + ... + βk·xki + ui

Pi = 1 / (1 + e^(-zi))  =  e^zi / (1 + e^zi)   ← Sigmoid 함수
```

- `Pi`: 이벤트 발생 확률 (항상 [0,1] 범위)
- `zi`가 클수록 `Pi`도 커짐

### 승산비(Odds Ratio)와 로그 승산비

```
Pi / (1 - Pi) = e^zi                          ← 승산비
log(Pi / (1 - Pi)) = zi = β0 + β1·x1 + ...   ← 로그 승산비 (선형화)
```

- **승산비**: 이벤트 미발생 확률 대비 발생 확률의 비율. 범위 [0, +∞)
- **로그 승산비**: 범위 (-∞, +∞). 선형모델 형태로 추정 가능
- xk가 1 단위 증가 → 로그 승산비는 βk 증가, 승산비는 e^βk 배 변화

### 추정 방법

OLS(최소제곱법) 아닌 **MLE(최대우도추정, Maximum Likelihood Estimation)** 사용.  
Python/통계 패키지가 자동 처리.

### 실전 예제: 미국 대통령 선거 (1880~2016)

```
log(P공화당 / (1 - P공화당))
  = -0.93 - 0.09·[경제성장률] + 0.08·[물가상승률] + 1.07·[현재 집권 여부]
```

해석:
- 공화당이 집권당일 때 → 승산비 e^1.07 = **2.92배** 상승 (경제·물가 불변 가정)
- 평균 경제 상황(성장률 0.65%, 물가 2.56%, 집권여부 0.54) → P공화당 = **0.45 (45%)**
- 임계값 0.5 기준으로 이벤트 분류 가능

### 파이썬 코드

```python
from sklearn.linear_model import LogisticRegression
from sklearn.datasets import load_breast_cancer

X, y = load_breast_cancer(return_X_y=True)

logistic = LogisticRegression(max_iter=10000)
logistic.fit(X, y)

print(logistic.coef_)       # 회귀계수
print(logistic.intercept_)  # 절편

# 예측
logistic.predict(X)               # 분류 결과 (0 or 1)
logistic.predict_proba(X)         # 각 클래스별 확률 (n×2 행렬)
logistic.predict_log_proba(X)     # 확률의 log값
logistic.score(X, y)              # 정확도 → 0.9578 (95.78%)
```

> `predict_log_proba`의 (2열 - 1열) = log(p/(1-p)) = 선형 회귀 부분식

## 2. 나이브 베이즈 분류기 (Naive Bayes Classifier)

### 베이즈 정리

```
P(A|B) = P(A) · P(B|A) / P(B)
```

- `P(A|B)`: B가 주어졌을 때 A 발생 확률 (사후 확률)
- 강점: `P(A|B)`를 `P(B|A)`를 이용해 계산

**예제**: 질병 검사 (유병률 1%, 민감도 99%, 특이도 99%)  
→ 양성이어도 실제 아플 확률 = **50%** (0.01×0.99 / (0.01×0.99 + 0.99×0.01))

### 나이브 베이즈 원리

```
P(Ck | x1, ..., xn) ∝ P(Ck) · Π P(xi | Ck)
                                i=1~n
```

- xi들이 **서로 독립**이라고 가정 ("나이브"한 가정)
- P(X)는 클래스와 무관한 상수이므로 비례식으로 처리
- 각 클래스별 속성 확률 분포는 **training data**로 학습

## 3. 나이브 베이즈 실전 모델

### 3.1 W/L 모델 (Winner/Loser)

**개념**: 과거 주가 상승 종목(Winner) vs. 하락 종목(Loser)의 특성을 학습 → 신규 종목 분류

**Training data**: KOSPI200 종목 × 12분기 = 2,400개 샘플 (2012.9~2015.6)

**분류 기준**:
- Winner: 다음 분기 상대수익률 ≥ 0%
- Loser: 다음 분기 상대수익률 < 0%

**속성 5개**: B/P (Book to Price), 매출액 증가율, TP 괴리도, 주가 변동성, ROE

**클래스별 통계 (Winsorization 5% 적용)**

| 클래스 | B/P(%) | 매출액증가율(%) | TP괴리율(%) | 주가변동성(%) | ROE(%) |
|--------|--------|----------------|------------|--------------|--------|
| Winner 평균 | 98.9 | 8.6 | 26.8 | 33.4 | 10.0 |
| Winner 표준편차 | 50.2 | 11.7 | 12.0 | 7.4 | 6.3 |
| Loser 평균 | 96.5 | 7.8 | 26.5 | 33.9 | 10.1 |
| Loser 표준편차 | 47.4 | 10.6 | 11.3 | 7.6 | 6.2 |

> ROE 차이 거의 없음 → ROE는 Winner/Loser 변별력이 낮은 지표 (분류기가 자동으로 중립 처리)

**분류 계산** (정규분포 PDF 가정):
```
P(xi | Ck) = (1 / √(2π·σ²)) · exp(-(x - μ)² / 2σ²)
```

A종목 (B/P=217.9%, 매출액증가율=0.7%, ...) 계산 결과:
- `log P(Winner|X)` = -21.7
- `log P(Loser|X)` = -22.0
- → Winner로 분류 (Winner 확률이 더 높음)

**W/L 모델의 장점**
1. 변별력 약한 지표를 자동으로 걸러냄 (ROE처럼 두 클래스 분포가 유사하면 중립 역할)
2. Training data를 rolling 방식으로 업데이트 → 전략의 점진적 자동 교체 가능

### 3.2 BoW 모델 (Bag of Words) — 텍스트 마이닝

**개념**: 텍스트를 단어 집합으로 표현 → 클래스(긍정/부정) 분류

```
P(xi | Ck) = (해당 단어의 Ck training 문구 내 출현횟수) / (Ck training 문구 전체 단어수)
```

**Laplace Smoothing** (0 확률 방지):
```
P(xi | Ck) = (출현횟수 + alpha) / (전체 단어수 + 어휘 종류수 × alpha)
```

- 새로운 단어도 0이 아닌 낮은 확률로 처리
- alpha = 0.2 (관행)

**활용 예**:
- 긍정/부정 영화 리뷰 training → 새 리뷰 자동 분류
- 증시 긍정/부정 뉴스 training → 실시간 뉴스 감성 분석
- DART 공시 자동 분류

**Python 코드 (110줄, Python 2.7)**:
```python
import re, math

# 핵심: 단어 출현 확률의 log 합산
classify1 = math.log(prob1) + calculate_doc_prob(
    create_BOW(training1_text), create_BOW(testing_text), alpha)
classify2 = math.log(prob2) + calculate_doc_prob(
    create_BOW(training2_text), create_BOW(testing_text), alpha)

# 상대확률로 변환
pro1 = math.exp(classify1) / (math.exp(classify1) + math.exp(classify2))
```

**결과 예시**: "This movie was really really bad... haven't seen worse in my life"  
→ 긍정 확률 5.7%, 부정 확률 94.3% → **Negative** 판정

## 4. 로짓 vs 나이브 베이즈 비교

| 항목 | 로짓 모델 | 나이브 베이즈 |
|------|-----------|---------------|
| 출력 | 이벤트 발생 확률 + 계수 해석 | 클래스 분류 확률 |
| 입력 데이터 | 수치형 | 수치형 or 텍스트 |
| 속성 독립 가정 | ❌ | ✅ (나이브 가정) |
| 주요 용도 | 확률 추정, 계수 해석 | 분류, 텍스트 마이닝 |
| 추정 방법 | MLE | Training data 통계 |

| 공시 자동 분류 | 나이브 베이즈 BoW | DART 공시 감성 판별 |
