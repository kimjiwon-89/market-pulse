# 퀀트 모델링 (5): 포트폴리오 밸류에이션 (가중 조화평균)

> 출처: 삼성증권 퀀트 모델링 A to Z (5) 포트폴리오 밸류에이션 지표 계산법 (2022.5.17)

---

## 1. 핵심 원리

**PER, PBR 등 상대 밸류에이션 지표 합산 시 → 가중 조화평균(Weighted Harmonic Mean) 사용**

A/B 형태의 지표를 여러 샘플에 걸쳐 합산할 때:

| 합산 기준 | 사용 평균 방법 |
|----------|-------------|
| 분모 B의 정보로 합산 | **가중 산술평균** |
| 분자 A의 정보로 합산 | **가중 조화평균** |

> PER = 주가(분자) / EPS(분모) → 주가(분자) 기준으로 합산 → **가중 조화평균**  
> 배당수익률 = 배당금 / 주가(분모) → 주가(분모) 기준으로 합산 → **가중 산술평균**

---

## 2. 수식

### 가중 산술평균

```
가중 산술평균 = (w1·x1 + w2·x2 + ... + wn·xn) / (w1 + w2 + ... + wn)
```

### 가중 조화평균

```
가중 조화평균 = (w1 + w2 + ... + wn)
               ─────────────────────────────────────────
               w1·(1/x1) + w2·(1/x2) + ... + wn·(1/xn)
```

### 포트폴리오 PER 증명

n개 종목 포트폴리오에서:
- `mv_pi`: 포트폴리오 내 i번째 종목의 투자금액
- `ni_pi = mv_pi / PERi`: i번째 종목의 포트폴리오 내 순이익 규모

```
PERport = Σ(mv_pi) / Σ(ni_pi)

        = (mv_p1 + mv_p2 + ... + mv_pn)
          ─────────────────────────────────────────────────────────
          mv_p1·(1/PER1) + mv_p2·(1/PER2) + ... + mv_pn·(1/PERn)
```

즉, **PERi들을 mv_pi(투자금액)로 가중 조화평균**한 수식과 동일.

---

## 3. 직관적 이해

포트폴리오의 펀더멘털 계산은 "투자금액만큼의 미니 기업을 샀다"는 개념으로 접근:

예) 삼성전자 450만원 매수 = "시가총액 450만원, 순이익 39만원인 미니 기업" 매수

**포트폴리오 2종목 예시**:
- A주식 200만원, PER=10배 → 순이익 20만원
- B주식 50만원, PER=100배 → 순이익 0.5만원
- 포트폴리오 합산 PER = (200+50) / (20+0.5) = 250 / 20.5 = **12.2배**

---

## 4. 실전 예제

### 가상 포트폴리오

| 종목명 | Fwd P/E (배) | 포트폴리오 비중 (%) |
|--------|-------------|-------------------|
| 삼성전자 | 9.2 | 50 |
| LG에너지솔루션 | 84.7 | 30 |
| NAVER | 27.6 | 20 |

### 가중 조화평균으로 PER 계산

```
PERport = (0.5 + 0.3 + 0.2)
          ──────────────────────────────────────
          0.5×(1/9.2) + 0.3×(1/84.7) + 0.2×(1/27.6)

        = 1 / (0.05435 + 0.00354 + 0.00725)
        = 1 / 0.06514
        ≈ 15.4배
```

> 단순 가중 산술평균으로 계산하면: 0.5×9.2 + 0.3×84.7 + 0.2×27.6 = 35.9배 (오답)  
> 고밸류 LG에너지솔루션에 과도하게 왜곡됨

## 5. 주가지수 합산 지표 계산 시 주의사항

KOSPI200, S&P500, MSCI 등 **유동시가총액 가중방식** 지수도 마찬가지:

- 구성종목 전체 기업가치가 아닌 **유동시가총액 비중만큼**만 보유하는 가상 포트폴리오
- `시가총액 합계 / 순이익 합계` 단순 합산식 사용 금지
- **유동시가총액 비중을 가중치로 한 가중 조화평균**으로 계산해야 정확

---

## 6. 밸류에이션 지표별 적용 방법

| 지표 | 구조 | 포트폴리오 합산 방법 |
|------|------|---------------------|
| PER | 주가(↑) / EPS | 가중 조화평균 |
| PBR | 주가(↑) / BPS | 가중 조화평균 |
| PCR | 주가(↑) / 영업현금흐름 | 가중 조화평균 |
| 배당수익률 | 배당금 / 주가(↑) | 가중 산술평균 |

> 분자에 가격이 있으면 조화평균, 분모에 가격이 있으면 산술평균

---

## 7. 파이썬 코드

```python
import numpy as np

per = np.array([9.5, 92.4, 29.0])
wgt = np.array([500, 300, 200])     # 투자금액 or 비중

# 가중 조화평균 = 가중치 합 / (가중치/지표)의 합
per_port = wgt.sum() / (wgt / per).sum()
print(per_port)  # → 15.93
```

### 엑셀 VBA 함수

```vba
Function wgtHarmonic(w, z)
    ' 가중 조화평균 (세로 범위 입력)
    sum_up = 0
    sum_down = 0
    rownum = w.Rows.Count
    For i = 1 To rownum
        this_w = w(i, 1)
        this_z = z(i, 1)
        If this_w <> "" And this_z <> "" And IsNumeric(this_w) And IsNumeric(this_z) Then
            sum_up = sum_up + this_w
            sum_down = sum_down + this_w / this_z
        End If
    Next i
    wgtHarmonic = sum_up / sum_down
End Function
```

## 8. 투자 활용 요약

| 활용 목적 | 방법 |
|-----------|------|
| 포트폴리오 PER/PBR 산출 | 개별 종목 지표 + 투자비중 → 가중 조화평균 |
| 지수 합산 밸류에이션 확인 | 유동시가총액 비중을 가중치로 가중 조화평균 |
| 포트폴리오 배당수익률 | 투자비중으로 가중 산술평균 |
| 고밸류/저밸류 타입 구분 | 포트 전체 PER/PBR 수준 비교로 성장주 vs 가치주 판별 |

> **핵심**: PER처럼 가격이 분자에 오는 지표는 가중 조화평균, 배당수익률처럼 분모에 오면 가중 산술평균.  
> 조화평균을 쓰지 않으면 고밸류 종목에 왜곡되어 포트폴리오 PER이 실제보다 크게 과대평가된다.
