### NetBuyingList 주 단위 네비게이션 + 오늘 컬럼 강조

- `src/pages/NetBuyingList/index.tsx`
  - `getMondayOf(dateStr)` 유틸 추가 — 해당 날짜가 속한 주의 월요일 계산
  - `getThisWeekBounds(today)` 유틸 추가 — 이번주 월~min(오늘, 금) 범위 반환
  - 초기 날짜 범위: "4영업일 전~오늘" → 이번주 월~오늘로 변경
  - `shiftWeek(±1)`: 5영업일 이동 → ±7일(월 기준) 이동, 항상 월-금 full week 표시
  - `resetToToday()`: `dates.length - 1` 사용하던 버그 제거 → `getThisWeekBounds`로 통일
    - 버그 원인: 오늘이 주말이면 `dates`에 오늘 미포함 → `dates.length` 감소 → 매 클릭마다 시작일 하루씩 밀림
  - 오늘 컬럼 헤더: 날짜 대신 **"오늘"** 텍스트, 배경 `--accent-soft`, 텍스트 `--accent`, bold
  - 오늘 컬럼 서브헤더(2·3행)도 동일 배경색으로 컬럼 전체 강조

#### 플랫폼 정체성 확립
- 방향: **통계 기반 분석 플랫폼** — 공개 데이터 + 통계 모델 + 시각화 + 누적 성적 추적

#### 퀀트 모델 시뮬레이터 방향 확정
- 플랫폼 제공 모델(우리가 구현) + 사용자 정의 모델(GUI 조건 빌더) + 모델 조합(Blending)
- 모의 투자 방식 (실제 매매·증권사 연동 없음)
- 즉시 구현 가능 모델 4개 (모멘텀·외국인추종·거래량급등·섹터로테이션), DART 연동 시 4개 추가
- 연 20%+ 검증 퀀트 모델 리스트업: Magic Formula(17~30%), 강환국 울트라(33%), GP/A(69%) 등

#### 로또 방향 검토
- 현재 전략별 소규모 풀(10개) + 조합 3개 방식 유지
