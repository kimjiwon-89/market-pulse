### Mock 데이터 제거 후 버그 수정 (브랜치: fix/api-params-lotto-analysis)

Mock 제거 이후 대부분의 대시보드 데이터가 표시되지 않는 문제와 로또 페이지 데이터 미표시 문제 수정.

**원인 분석:**
- KIS API 파라미터 이름 대소문자 불일치: `fetchForeignTradeTop`(작동)은 대문자 사용, IndexService·InvestorService·StockDetailService는 소문자 사용 → KIS API가 응답 거부
- 로또: `lotto_result`는 있지만 `lotto_analysis_pool`이 없어 strategies 빈 배열 반환 → 프론트엔드에서 아무것도 표시 안 됨

**수정 내용:**
- `IndexService.fetchAndSave()`: 파라미터 대소문자 소문자→대문자 통일
- `InvestorService.saveMarketFlowSnapshots()`: 동일
- `StockDetailService.getInvestor()`: 동일
- `LottoService.getLatest()`: analysis pool이 없을 때 `analyzeOnly()` 자동 호출
- `LottoAnalysis/index.tsx`: strategies 빈 배열일 때 안내 메시지 표시

**수정 파일:**
- `market-pulse-api/src/main/java/com/marketpulse/domain/index/service/IndexService.java`
