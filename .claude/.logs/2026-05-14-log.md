### JWT 인증 구현 (8단계)

#### 방식: JWT 토큰 + Stateless

세션 방식 대신 JWT(JSON Web Token) 방식 선택.
로그인 성공 시 토큰 발급 → 이후 모든 요청 헤더에 `Authorization: Bearer <token>` 첨부.

- **`application-local.yml`** — `app.auth.username/password`, `app.jwt.secret` 추가

#### 백엔드 신규 파일

| 파일 | 설명 |
|------|------|
| `global/auth/JwtUtil.java` | 토큰 생성·검증·username 추출. 유효기간 24시간 |
