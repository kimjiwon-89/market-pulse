### 개인화 퀀트 모델 빌더 상품 방향 정리
- 공개 플랫폼 모델은 일반 사용자도 전체 조회 가능하게 하고, 일반 계정은 `내 퀀트 모델` 1개만 등록하는 방향으로 정리
- Pro 계정은 여러 모델 등록, 직접 모델 생성, 고급 팩터/긴 기간 백테스트, 알림, AI 모델 빌더를 사용할 수 있도록 구독 구조 초안 작성
- 사용자 모델은 `MP_CORE` 같은 기본 모델 위에 투자 성향, 선호 팩터, 제외 조건, 리밸런싱 주기를 얹는 블록 조립형으로 시작하는 방향 기록
- AI API는 필수가 아니라 Pro 고급 UX로 두고, 자연어 투자법을 검증 가능한 모델 설정 JSON으로 바꾸는 역할로 제한
- 과최적화 방지를 위해 고정 검증 기간, 필수 위험 지표, 활성화 제한 조건을 문서화
- 사용자 모델은 동의 기반 익명화/집계/검증을 거쳐 플랫폼 모델 개선 후보로만 활용하는 원칙 정리
- 수정 파일:
  - `.claude/.features/quant-marketplace.md`
