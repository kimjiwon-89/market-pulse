PLANNING 메모 도메인 리모델링

범용 메모 시스템 개편

날짜+시장 1개 메모에서 기능·종목·날짜 맥락이 있는 여러 메모 구조로 확장

문제 정의

현재

날짜+시장당 1개

현재 `investor_memo`는 `memo_date + market` unique라 같은 날 같은 시장에는 메모를 하나만 남길 수 있다.

한계

종목 맥락 부재

순매수도에서 삼성전자에 남긴 메모인지, 시장 전체 메모인지 구분하기 어렵다.

목표

투자 관찰 기록

메모를 기능, 날짜, 시장, 종목에 연결된 독립 기록으로 바꾼다.

사용 흐름

1. 순매수도 조회
2026-05-19 KOSPI 순매수도에서 삼성전자 확인
2. 행 메모 작성
삼성전자 행에서 메모 추가
3. 맥락 저장
sourceType=NET_BUY, 날짜, 시장, 종목코드 저장
4. 원화면 조회
같은 날짜/종목 행에서 메모 확인
5. 전체 리스트
/memo에서 필터로 다시 찾기

신규 메모 모델

필드설명예시
memoDate메모가 연결된 기준일2026-05-19
sourceType메모가 작성된 기능NET_BUY
market시장KOSPI
stockCode종목 코드, 선택값005930
stockName종목명, 선택값삼성전자
title짧은 제목, 선택값순매수도 1위 관찰
content메모 본문외국인 순매수 강함. 반도체 수급 확인.

화면별 연결

순매수도

  • 종목 행 단위 메모
  • 날짜+시장+종목 필터로 조회
  • 메모 존재 시 행에 표시

투자자 동향

  • 날짜+시장 전체 메모
  • 기존 메모 UI와 점진 교체
  • 종목 없는 메모 허용

종목 상세

  • 종목 기준 메모 타임라인
  • 향후 가격 스냅샷 연결
  • 전체 메모에서 종목 필터 가능

결정 필요 사항

항목선택지권장
메모 공개 범위전체 공유 / 로그인 사용자 개인개인 메모
기존 메모 처리병행 / 즉시 마이그레이션1차 병행
첫 적용 화면순매수도 / 투자자 동향 / 종목 상세순매수도

1차 Acceptance Criteria

  • 로그인 사용자는 순매수도 특정 날짜/시장/종목에 여러 메모를 작성할 수 있다.
  • 같은 맥락에 여러 메모가 생성되며 기존처럼 덮어쓰지 않는다.
  • 전체 메모 리스트에서 기능, 날짜 범위, 시장, 종목, 키워드 필터가 동작한다.
  • 비로그인 사용자는 메모 작성/수정/삭제가 차단된다.
  • 기존 날짜+시장 메모 API는 깨지지 않는다.
