Quant Model Redesign

작성일: 2026-05-20 · 현재 5모델 확정 · 최종 방향: 단기/중기/장기 × 위험형/안정형 = 6모델 체계

이 문서의 수익률은 특정 기간의 공개 논문·책·백테스트 기준입니다. 실거래 성과를 보장하지 않으며, 한국 시장 적용 전 생존편향, 거래비용, 세금, 유동성, 재무 데이터 시점 지연을 별도 검증해야 합니다.

최종 선정 5모델

단기위험형

MP-PEAD · Earnings Drift

12.5%

실적 발표 후 어닝 서프라이즈와 발표 전후 가격 반응이 좋은 종목을 2~12주 보유.

역할: 5번째 단기투자 모델.

중기위험형

MP-DM · Dual Momentum

17.43%

상대 모멘텀 1위 자산을 고르고, 절대 모멘텀이 약하면 방어자산으로 이동.

장점: 가격 데이터만으로 구현 가능.

중기안정형

MP-CF · Conservative Formula

15.1%

저변동성 종목군에서 모멘텀과 순주주환원율로 최종 선별.

주의: 순주주환원율 데이터 필요.

장기위험형

MP-MF · Magic Formula + Momentum

30.8%

Earnings Yield와 ROIC에 6개월 모멘텀 필터를 결합.

주의: 재무 데이터 필수.

장기안정형

MP-PF · Piotroski Value Quality

23%

저 P/B 종목 중 F-Score 8~9 종목을 선별하는 가치+재무건전성 모델.

주의: 재무제표 시점 관리가 핵심.

단기 안정형 후보

MP-STR은 최근 1~5거래일 과매도 종목 중 유동성, 스프레드, 변동성 필터를 통과한 종목만 주간 단위로 거래하는 모델입니다.

거래비용과 슬리피지에 매우 민감해서, 운영 모델로 넣기 전 비용 차감 검증이 먼저 필요합니다.

DB 확장안

CREATE TABLE quant_model (
    id BIGSERIAL PRIMARY KEY,
    code VARCHAR(30) NOT NULL UNIQUE,
    name VARCHAR(100) NOT NULL,
    category VARCHAR(30) NOT NULL,
    horizon VARCHAR(20) NOT NULL,
    risk_profile VARCHAR(20) NOT NULL,
    description TEXT,
    rebalance_cycle VARCHAR(20) NOT NULL,
    min_public_cagr NUMERIC(8,4),
    source_summary TEXT,
    params JSONB,
    is_active BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW()
);

구현 순서

1quant_model 리소스와 5개 모델 seed 생성
2horizon, riskProfile, dataReadiness 필드 추가
3MP-DM 가격 기반 모델 먼저 구현
4MP-PEAD를 가격 반응 proxy로 MVP 구현
5MP-CF를 저변동성+모멘텀 MVP로 구현
6재무/실적 데이터 적재 설계
7MP-MF, MP-PF 구현
8MP-STR 후보 검증 후 6모델 체계 완성
