Quant Return Boost 기획

무료 데이터 기반 모델의 실제 백테스트 월 10% 목표 실험 설계. 월 10%는 보장 수익률이 아니라 후보 필터링과 랭킹 기준입니다.

목적

현재 `/api/quant`와 `/quant`에 구현된 백테스트 시스템을 확장해 모델별 파라미터 실험, 비용 반영, 편향 방지, 과최적화 방지 리포트를 한 화면에서 비교한다.

필수월 10% 목표는 수익 보장이 아니라 실험 후보를 선별하는 목표값과 결과 배지 기준으로만 사용한다.

현재 구조 반영

백엔드: `domain/quant` 도메인, `QuantController`, `QuantBacktestService`, `AbstractQuantStrategy`, `MarketDailyPriceMapper.xml` 기반.

프론트: `/quant` `QuantBacktest` 페이지, 전략 탭, EquityChart, PerformanceCards, AllocationChart, TradeTimeline 기반.

핵심 리스크 통제

필수신호 산출은 `signalDate` 이전 데이터만 사용하고, 주문 체결은 다음 거래일 `executionDate` 가격으로 계산한다.

필수수수료 0.015%, 매도세 0.18%를 모든 매수/매도와 리밸런싱에 반영한다.

필수학습/검증/테스트 구간 분리와 walk-forward 결과를 저장해 단일 기간 과최적화를 방지한다.

IDAcceptance Criteria
BE-1모든 experiment variant의 `signal_date`는 `execution_date`보다 이전 날짜로 저장된다.
BE-2모든 매도 거래에는 수수료와 세금이 0보다 크거나 거래금액이 0일 때만 0으로 저장된다.
BE-3월 10% 목표 달성 여부는 `target_achieved` boolean으로 저장되며 보장 수익 문구는 응답에 없다.
BE-4walk-forward window가 2개 이상 없으면 실험 run 상태가 FAILED가 된다.
FE-1`/quant`에서 실험 결과 탭이 렌더링되고 variant별 월환산, 총수익, MDD, Sharpe, 비용, bias 상태를 표시한다.
FE-2월 10% 이상 variant는 “목표 달성” 배지만 표시하며 “보장” 문구가 없다.
