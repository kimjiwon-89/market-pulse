6개 모델을 멈추고, 검증 가능한 단일 Core 모델부터 만든다

월 15% 이상을 꾸준히 유지하는 모델은 요구사항으로 보장할 수 없다. 이 프로젝트에서는 `targetMonthlyReturn = 0.15`를 목표/필터 기준으로 두고, MDD, Sharpe, 승률, 손익비, 거래비용, walk-forward 성과를 함께 통과해야 한다.

모델 코드MP_CORE

모델 파이프라인

1. Universe 거래대금, 시가총액, 결측, 거래 가능성 필터
2. Feature 모멘텀, 변동성, 추세, 수급, 시장 국면 생성
3. Train 24개월 학습, 6개월 검증, 6개월 테스트 rolling
4. Signal 상승 확률, 점수, 랭크, 목표 비중 산출
5. Backtest 손절, 익절, 비용, 세금, 현금 비중 반영

MVP 피처

  • 5일, 20일, 60일 수익률
  • 20일, 60일 변동성
  • 20일 평균 거래대금과 거래량 z-score
  • 20/60/120일 이동평균 대비 가격 위치
  • 60일 고점 대비 drawdown
  • 외국인/기관 5일, 20일 순매수 강도
  • KOSPI/KOSDAQ 시장 국면과 지수 변동성

포트폴리오 규칙

  • P(WINNER) >= 0.55 종목만 진입 후보
  • 상위 topN=10 종목 편입
  • 종목별 최대 비중 15%
  • 정상 국면 최대 주식 100%, 위험 국면 최대 30%
  • 손절 -7%, 익절 +15% 또는 trailing stop
  • 매수 수수료 0.015%, 매도 수수료 0.015%, 매도세 0.18%

.claude/quant 자료를 모델에 반영하는 방식

자료 핵심 내용 MP-CORE 활용 방식
01-회귀분석.md OLS, Ridge, LASSO, Elastic Net, 다중공선성, 과적합 방지 1차 예측 모델은 Random Forest로 가되, 피처 후보가 많아지면 LASSO/Elastic Net을 피처 선택 보조 모델로 사용한다. 수익률 민감도와 설명 가능한 factor beta 분석에도 회귀식을 사용한다.
02-시계열-HP필터.md 시계열을 장기 추세와 단기 순환으로 분리 KOSPI/KOSDAQ 지수와 개별 종목 가격에 대해 추세 이탈률, 사이클 위치, 과열/침체 정도를 만드는 시장 국면 피처로 활용한다. 단, HP 필터는 최근 값이 소급 수정될 수 있어 실전 신호에는 rolling/과거 데이터 기준 계산만 허용한다.
03-분류모델.md 로짓, 나이브 베이즈, Winner/Loser 분류 향후 20영업일 성과를 WINNER / NEUTRAL / LOSER로 나누는 레이블 설계의 근거로 사용한다. 로짓은 Random Forest 확률값 검증과 단순 baseline 모델로 두고, 나이브 베이즈의 W/L 사고방식은 클래스별 피처 분포 점검에 사용한다.
04-머신러닝-랜덤포레스트.md 결정트리, 랜덤포레스트, KOSPI 단기예측 AI 모델, feature importance MP-CORE의 중심 알고리즘이다. 여러 피처의 비선형 조합을 학습하고 P(WINNER)를 산출한다. feature importance를 화면에 표시해 모델이 어떤 근거로 종목을 골랐는지 설명한다.
05-포트폴리오-밸류에이션.md PER/PBR 등 포트폴리오 지표는 가중 조화평균 사용 재무 데이터가 붙는 2차 단계에서 포트폴리오 PER/PBR을 잘못된 산술평균이 아니라 가중 조화평균으로 계산한다. 1차 MVP에서는 비중 계산, 리스크 제한, 포트폴리오 성과 집계 원칙으로 반영한다.

정리된 수식의 실제 활용

수식/개념 사용 위치 산출물
β = (X'X)^(-1)X'y, 회귀 beta 시장 민감도, factor 민감도, benchmark 대비 설명력 분석 종목별 시장 beta, 수급 beta, 모멘텀 beta
LASSO / Elastic Net penalty 피처가 늘어날 때 과적합과 중복 피처 제거 학습에 투입할 핵심 피처 후보 목록
HP filter trend/cycle 시장 국면과 추세 이탈 측정 추세 상단/하단, 과열/침체 score, cash regime
Sigmoid / odds 로짓 baseline, 확률 score sanity check 상승 확률 해석 기준, Random Forest 확률 보정 참고
Gini impurity Random Forest tree split 비선형 매수 후보 분류 모델
Confusion matrix, Precision, Recall, F1 모델 검증 WINNER 정밀도, 놓친 기회, 오탐률
가중 조화평균 2차 재무 피처와 포트폴리오 valuation 집계 포트폴리오 PER/PBR, 성장/가치 성향 표시

만들 알고리즘

  • Universe 필터: 거래대금 상위, 시가총액, 결측, 거래 가능성으로 후보군 제한
  • Feature 생성기: 가격, 거래량, 수급, 지수 국면을 날짜별 feature matrix로 변환
  • Label 생성기: 20영업일 후 성과로 WINNER / NEUTRAL / LOSER 생성
  • Random Forest 학습기: walk-forward 방식으로 학습, 검증, 테스트 분리
  • 확률 기반 랭커: P(WINNER), 변동성, 유동성을 합쳐 최종 score 산출
  • 포트폴리오 엔진: topN, 비중 제한, 손절/익절, 현금화, 거래비용 반영
  • 성과 검증기: 월환산 수익률, MDD, Sharpe, 승률, 손익비, 회전율 산출

필요 데이터

  • 필수: 종목 OHLCV, 거래량, 거래대금, 시가총액, 종목명, 시장 구분
  • 필수: KOSPI/KOSDAQ 지수 OHLCV와 benchmark 수익률
  • 중요: 외국인/기관 종목별 순매수 금액과 수량
  • 중요: 거래정지, 관리종목, 신규상장 여부 필터
  • 2차: PER/PBR/ROE/매출성장률/영업이익률 등 재무 데이터
  • 2차: 실적 발표일, 컨센서스, 어닝 서프라이즈
  • 2차: 뉴스/공시 감성, 이벤트 리스크

거래정지/관리종목 필터 명시적 필터 데이터 확인 필요 부분 가능 KRX 상태 데이터, 결측/거래량 0 기반 보조 필터

예상 수익률 시나리오

시나리오 전제 월환산 기대 범위 연환산 단순 환산 판단
보수 가격/거래량 위주, 수급 데이터 제한, 시장 국면 필터만 적용 3% ~ 5% 36% ~ 60% 현실 검증의 1차 기준. MDD가 낮으면 의미 있음
기준 수급 feature 안정화, 거래비용 반영, topN/손절/익절 튜닝 성공 5% ~ 8% 60% ~ 96% 서비스 MVP에서 노릴 수 있는 공격적 목표
공격 강한 상승장, 수급/모멘텀 동시 작동, 회전율 관리 성공 8% ~ 15% 96% ~ 180% 목표 구간. 지속 가능성은 walk-forward로 별도 검증 필요
목표 초과 특정 장세에서 급등주 포착률이 높고 손절이 잘 작동 15% 이상 180% 이상 가능성은 열어두되 기본 기대값으로 두면 안 됨

위 수익률은 현재 자료와 설계 기준의 사전 추정치다. 실제 예상치는 데이터 적재 후 비용 차감 walk-forward 백테스트를 돌린 뒤에만 확정할 수 있다. 특히 월 15% 이상은 목표 상단이지 안정적인 기대수익률로 표시하면 안 된다.

기존 구조 정리

대상 처리 방향 이유
기존 6개 모델 기획 보류 데이터 요구사항이 크고, 모델별 검증 기준이 분산됨
