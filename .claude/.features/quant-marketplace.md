# 퀀트 모델 시뮬레이터 / 개인화 모델 빌더

**상태**: 아이디어 단계 (스펙 미확정)  
**서비스 정체성**: 퀀터/퀀터스 브랜딩의 핵심 기능  
**상품 방향**: 공개 모델 조회 + 계정별 모델 등록 + Pro 구독형 개인화 퀀트 모델 빌더

---

## 컨셉

퀀트 전략을 배우고 실험하는 모의 투자 플랫폼.  
플랫폼 제공 모델 + 사용자 정의 모델이 실시간 시장 데이터를 받아 자동으로 모의 매매하고,  
여러 모델을 비교하거나 조합해서 나만의 복합 전략을 만들 수 있다.  
실제 매매·증권사 연동 없음 — **교육·탐색·전략 실험 목적**.

확장 방향은 `MP_CORE` 같은 검증된 기본 모델을 바닥에 깔고, 사용자의 투자 성향과 선호 조건을 얹는 개인화 모델이다. 사용자가 만든 전략을 그대로 믿게 하는 것이 아니라, 기본 모델·공통 리스크 필터·고정 검증 기간·과최적화 경고가 안전장치 역할을 한다.

> 서비스 문구 주의: `수익률 보장`, `안정적 수익 보장`, `무조건 매수`, `확정 수익` 같은 표현은 쓰지 않는다. 대신 `검증된 모델 기반 개인화 전략`, `과거 여러 시장 구간에서 검증`, `과최적화 위험을 낮춘 모델 빌더`, `성과와 위험을 함께 보는 투자 판단 도구`처럼 표현한다.

## 구독/권한 모델

| 계정 구분 | 제공 기능 | 제한 |
|---|---|---|
| 비로그인/일반 조회 | 플랫폼 제공 공개 퀀트 모델 전체 조회, 모델 설명, 최근 후보, 백테스트 요약 | 개인 저장, 알림, 커스텀 모델 생성 불가 |
| 일반 계정 | 공개 모델 중 `내 퀀트 모델` 1개 등록, 해당 모델 기준 대시보드 조회 | 등록 모델 1개, 고급 팩터/긴 기간 백테스트/커스텀 생성 제한 |
| Pro 계정 | 여러 모델 등록, 내 모델 직접 생성, 고급 필터/팩터, 긴 기간 백테스트, 모델별 성과 비교, 알림/리밸런싱 히스토리 | 투자자문으로 오해될 수 있는 표현 금지, 모든 결과에 과거 성과 한계 표시 |
| Admin/Internal | 플랫폼 모델 템플릿 관리, 팩터 추가, 데이터 품질 확인, 사용자 모델 패턴 분석 | 운영자 전용 |

초기 상품 흐름:

```
공개 모델 전체 조회
  ↓
일반 계정: 내 퀀트 모델 1개 등록
  ↓
Pro 계정: 여러 모델 등록 + 내 모델 만들기
  ↓
Pro 고급: AI 모델 빌더 + 긴 기간 백테스트 + 알림
```

## 플랫폼 제공 모델 vs 사용자 모델

### 플랫폼 제공 모델

- 모든 사용자가 조회 가능
- 일반 계정은 이 중 1개를 `내 퀀트 모델`로 등록 가능
- Pro 계정은 여러 개를 등록하고 비교 가능
- 예: `MP_CORE`, 모멘텀, 외국인 추종, 저변동, 가치, 수급형

### 사용자 모델

사용자 모델은 완전 자유 수식보다 **검증된 블록 조립형**으로 시작한다.

```
기본 MP_CORE / 플랫폼 모델
  + 사용자 성향
  + 선호 팩터 가중치
  + 제외 조건
  + 리밸런싱 주기
  + 포트폴리오 제약
= 개인화 퀀트 모델
```

사용자 입력 예시:

- 투자 스타일: 가치 / 성장 / 모멘텀 / 배당 / 저변동 / 수급
- 투자 기간: 단기 / 스윙 / 중장기
- 제외 조건: 적자기업 제외, 거래대금 낮은 종목 제외, 변동성 높은 종목 제외
- 점수 비중: 가치 30%, 성장 20%, 모멘텀 30%, 수급 20%
- 리밸런싱 주기: 매주 / 매월 / 분기

핵심 원칙:

- 우리 모델이 universe filter, 데이터 품질, 공통 리스크 필터를 먼저 적용한다.
- 사용자 모델은 후보군 전체를 새로 만드는 것이 아니라, 검증된 후보군 안에서 선호와 가중치를 반영한다.
- 사용자가 만든 모델은 항상 백테스트와 위험 진단을 통과해야 활성화할 수 있다.

## AI 모델 빌더 방향

AI API는 필수는 아니지만 Pro 전환을 유도할 수 있는 고급 UX다. 핵심 역할은 종목 추천이 아니라 사용자의 자연어 투자법을 **검증 가능한 모델 설정 JSON**으로 번역하는 것이다.

사용자 입력 예:

> 변동성 큰 종목은 싫고, 외국인이 꾸준히 사는 저평가 대형주 위주로 한 달에 한 번만 갈아타고 싶어.

AI 변환 예:

```json
{
  "style": ["VALUE", "LOW_VOLATILITY", "FOREIGN_FLOW"],
  "universe": {
    "market": ["KOSPI"],
    "minMarketCap": 1000000000000,
    "minTradingValue": 5000000000
  },
  "filters": [
    { "factor": "pbr", "operator": "lte_percentile", "value": 40 },
    { "factor": "volatility_20d", "operator": "lte_percentile", "value": 50 },
    { "factor": "foreign_net_buy_20d", "operator": "gte", "value": 0 }
  ],
  "weights": {
    "value": 0.4,
    "foreignFlow": 0.35,
    "lowVolatility": 0.25
  },
  "rebalance": "MONTHLY"
}
```

AI 사용 원칙:

- AI는 모델 설정 초안만 만든다.
- 저장 전 사용자가 반드시 확인/수정한다.
- 시스템이 지원하지 않는 조건은 거절하거나 지원 가능한 조건으로 대체 제안한다.
- AI가 직접 “이 종목을 사라”고 말하지 않는다.
- 최종 백테스트와 위험 진단은 룰 엔진이 수행한다.

MVP는 AI 없이 룰 빌더로 시작하고, 이후 Pro 기능으로 `말로 내 투자법 만들기`를 추가한다.

## 과최적화 방지 장치

사용자가 좋은 구간만 골라 백테스트하거나 조건을 과하게 맞추는 것을 막기 위해 검증 기간과 평가 지표를 플랫폼이 통제한다.

### 고정 검증 기간

사용자가 임의 기간 하나만 선택하지 못하게 하고, 아래 기간을 기본 검증 세트로 둔다.

| 구간 | 목적 |
|---|---|
| 최근 1년 | 최신 시장 대응력 확인 |
| 최근 3년 | 단기 과최적화 완화 |
| 상승장 구간 | 강세장에서 수익 추종력 확인 |
| 하락장 구간 | 최대 하락과 방어력 확인 |
| 횡보장 구간 | 잦은 매매와 비용 부담 확인 |

### 필수 평가 지표

- 시드머니
- 현재 평가액
- 평가 손익
- 월평균 수익률
- 최대 하락 경험
- 거래 비용
- 거래 횟수
- 승률
- 종목/섹터 쏠림
- 특정 구간 의존도
- 과최적화 위험 점수

### 활성화 제한 후보

아래 조건이면 모델 저장은 가능하되 실전 대시보드 활성화 전에 경고 또는 제한한다.

- 테스트 기간이 너무 짧음
- 거래 횟수가 너무 적음
- 수익 대부분이 특정 한두 거래에 집중
- 특정 종목/섹터 쏠림 과다
- 거래 비용 차감 후 성과 급락
- 최대 하락 경험이 사용자 위험 허용치를 초과
- 동일 팩터 중복으로 사실상 한 조건에 과의존

## 사용자 모델을 통한 플랫폼 모델 개선

Pro 사용자가 만든 모델은 플랫폼 기본 모델 개선 후보가 될 수 있다. 단, 바로 자동 반영하지 않고 익명화·집계·검증 단계를 거친다.

```
사용자 모델 생성
  ↓
사용자 동의 기반 익명화 수집
  ↓
성과/안정성/과최적화 위험 집계
  ↓
좋은 패턴을 내부 후보 팩터로 추출
  ↓
walk-forward / out-of-sample 검증
  ↓
MP_CORE_LATER 또는 신규 플랫폼 모델 후보로 승격
```

수집 원칙:

- 개인 식별 정보 제거
- 모델 설정과 성과 통계만 집계
- 개별 사용자의 포트폴리오/보유 종목을 공개 모델에 직접 반영하지 않음
- 성과 좋은 사용자 모델도 내부 검증을 통과해야 플랫폼 모델에 반영

이 구조의 목표는 사용자 참여를 통해 모델 아이디어 풀을 넓히되, 플랫폼 모델의 안정성과 설명 가능성을 유지하는 것이다.

## 플랫폼 제공 모델

### ✅ 즉시 구현 가능 (KIS·KRX API 현재 인프라로 충분)

| 모델명 | 원형 | CAGR(참고) | 핵심 팩터 | 매매 주기 |
|--------|------|-----------|-----------|----------|
| **모멘텀** | Trending Value 모멘텀 필터 | ~21% | 52주 수익률 상위 + 거래량 증가 추세 | 주 1회 |
| **외국인 추종** | — | — | 외국인 순매수 3일 연속 상위 종목 | 일 1회 |
| **거래량 급등 반등** | 역추세 전략 | — | 단기 낙폭 과대 + 거래량 바닥 후 급등 | 주 1회 |
| **섹터 로테이션** | — | — | 최근 1개월 강세 업종 상위 종목으로 교체 | 월 1회 |

### ⚠️ 재무 데이터 추가 필요 (DART OpenAPI 또는 FnGuide 연동)

| 모델명 | 원형 | CAGR(참고) | 핵심 팩터 | 필요 데이터 |
|--------|------|-----------|-----------|------------|
| **매직 포뮬러** | Joel Greenblatt Magic Formula | 17~30% | 이익수익률(EY) + 투하자본수익률(ROIC) | PER, ROIC |
| **GP/A 가치주** | 강환국 GP/A 전략 | 69% (소형주 포함) | 매출총이익/자산 + 소형주 필터 | GP, 총자산 |
| **울트라 멀티팩터** | 강환국 울트라 전략 | 33~45% | 가치(PER·PBR·PSR·PFCR) + 퀄리티(GP/A) + 성장 4팩터 | 재무제표 전반 |
| **QVM 복합** | Quality Value Momentum | 20%+ | 퀄리티 + 가치 + 모멘텀 3팩터 조합 | PBR, ROE, 모멘텀 |

> DART OpenAPI는 무료 공개. 재무 데이터 연동 시 위 4개 모델 추가 구현 가능.

## 사용자 정의 모델

GUI로 조건을 설정하면 플랫폼이 해당 조건에 맞게 자동으로 모의 매매 실행.

```
사용자가 설정하는 것
├── 종목 선정 조건 (AND/OR 조합)
│   예) 외국인 순매수 상위 20위 AND 거래량 전일 대비 +50% 이상
├── 매수 트리거 (조건 충족 시 자동 모의 매수)
├── 매도 조건 (목표 수익률 / 손절 기준 / 최대 보유 기간)
└── 시드머니 배분 방식 (균등 / 비중 가중)
```

- 공개 / 나만 보기 선택
- 1단계 MVP에서는 플랫폼 제공 모델만 → 이후 사용자 정의 모델 오픈

## 모델 조합 (Model Blending)

여러 모델을 섞어 복합 전략 생성.

```
예시: 내 복합 모델
├── 모멘텀 모델      × 40%
├── 외국인 추종      × 40%
└── 내가 만든 모델   × 20%
→ 신호 가중 합산 → 복합 모의 포트폴리오 운영
```

---

## 모의 매매 엔진

```
스케줄러 (모델별 주기마다)
  ↓
시장 데이터 수신 (KIS API · KRX API)
  ↓
각 모델 조건 판단 → 모의 매수/매도 결정
  ↓
DB 기록 (체결 시점 가격 스냅샷 저장)
  ↓
수익률 실시간 계산 (현재가 vs 매수 시점가)
```

- 초기 시드머니: 모델당 가상 1억 원 기준
- 슬리피지·세금 미반영 (기본) — 옵션으로 반영 가능하게 검토

### 퀀트 모델 페이지 구성 (`/quant`)

#### 1. 모델 탐색 (기본 화면)
```
┌─────────────────────────────────────────┐
│  [전체] [플랫폼 제공] [내 모델] [조합]   ← 탭
├─────────────────────────────────────────┤
│  정렬: 수익률↓  기간: 1M / 3M / 1Y / 전체│
├──────────┬──────┬──────┬────────────────┤
│ 모델명   │CAGR  │MDD   │현재 보유 종목 수│
│ 모멘텀   │+24.3%│-18%  │12종목          │
│ 외국인추종│+31.2%│-22%  │8종목           │
│ 매직포뮬러│+19.8%│-31%  │20종목          │
│ 내가만든A │+15.1%│-12%  │5종목           │
└──────────┴──────┴──────┴────────────────┘
```

#### 2. 모델 상세 (`/quant/:modelId`)
```
┌─────────────────────────────────────────┐
│ [모델명]  [전략 설명 한줄]  [내 모델 등록]│
├────────────┬────────────┬───────────────┤
│ 누적수익률 │  MDD       │  승률         │
│  +142%     │  -31%      │  58%          │
├─────────────────────────────────────────┤
│ 수익률 차트 (vs KOSPI 벤치마크 오버레이)  │
├─────────────────────────────────────────┤
│ 현재 보유 종목                           │
│ 종목명 / 매수일 / 매수가 / 현재가 / 수익률│
├─────────────────────────────────────────┤
│ 모의 매매 내역 (최신순)                  │
│ 날짜 / 종목 / 매수·매도 / 가격 / 수익    │
└─────────────────────────────────────────┘
```

#### 3. 모델 비교
```
┌─────────────────────────────────────────┐
│ 비교할 모델 선택 (최대 4개)              │
│ [모멘텀 ✕] [외국인추종 ✕] [+ 추가]      │
├─────────────────────────────────────────┤
│ 수익률 오버레이 차트                     │
│ (각 모델 색상 구분, KOSPI 회색 기준선)   │
├──────────┬──────┬──────┬───────┬────────┤
│          │CAGR  │MDD   │샤프   │승률    │
│ 모멘텀   │24.3% │-18%  │1.2   │58%     │
│ 외국인   │31.2% │-22%  │1.5   │62%     │
│ KOSPI    │8.1%  │-35%  │0.4   │—       │
└──────────┴──────┴──────┴───────┴────────┘
```

#### 4. 모델 조합 (`/quant/blend`)
```
┌─────────────────────────────────────────┐
│ 모델 선택 + 비중 설정                   │
│ [모멘텀]      ████████░░  40%           │
│ [외국인추종]  ████████░░  40%           │
│ [내 모델A]    ████░░░░░░  20%           │
├─────────────────────────────────────────┤
│ 예상 조합 수익률 시뮬레이션              │
│ (과거 데이터로 비중 조합 결과 미리보기)  │
└─────────────────────────────────────────┘
```

#### 5. 내 모델 만들기 (`/quant/create`)

## 기존 페이지와의 연결 포인트

| 기존 기능 | 연결 |
|-----------|------|
| `/stock/:code` 종목 상세 | 모델 보유 종목 클릭 시 바로 이동 |
| `/investor` 투자자동향 | 외국인 추종 모델이 근거로 사용하는 데이터 |
| `/net-buy` 순매수순위 | 모델 종목 선정 조건 설정 시 참고 데이터 |

## 개발 단계 (MVP → 확장)

| 단계 | 내용 |
|------|------|
| 1단계 | 플랫폼 모델 3~4개 + 모의 매매 엔진 + 수익률 조회 + 모델 상세 |
| 2단계 | 모델 비교 (오버레이 차트) + 내 모델 등록 기능 |
| 3단계 | 사용자 정의 모델 (조건 빌더) |
| 4단계 | 모델 조합 (Blending) + DART 재무 데이터 연동 → 매직포뮬러·GP/A 모델 추가 |

---

## 미결정 사항

- 사용자 공개 모델 어뷰징 방지 기준
- 모델 조합 신호 합산 방식 (단순 가중합 vs 앙상블)
- 수익률 계산에 거래 비용 반영 여부
- DART API 연동 시점 (2단계 vs 4단계)
