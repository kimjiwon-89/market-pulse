# 타로 기능

**상태**: 기획 확정, 개발 예정  
**페이지**: `/tarot` (Tarot)  
**성격**: 재미 콘텐츠 — 통계 기반 아님, 별도 카테고리

---

## 컨셉

무료 타로 뽑기. 사용자가 카드를 뽑으면 해석을 보여준다.  
1장(오늘의 카드) / 3장(과거·현재·미래) 스프레드 제공.

## 스프레드 구성

| 스프레드 | 카드 수 | 포지션 |
|----------|--------|--------|
| 오늘의 카드 | 1장 | 오늘의 에너지·메시지 |
| 과거·현재·미래 | 3장 | 과거 / 현재 상황 / 앞으로의 흐름 |

- 역방향(리버스) 카드 포함 여부: 포함 (뽑을 때 랜덤으로 정·역 결정)

## 해석 방식

**처음부터 Claude API 해석 사용** — 정적 텍스트 단계 없음.

기존 타로 해석 데이터(dariusk/corpora 등)는 1900년대 전통 해석 기반이라 현대 맥락과 맞지 않음.
Claude API로 현대적·개인화된 한국어 해석을 생성하는 방식으로 처음부터 시작.

```
프론트: 카드 뽑기 (랜덤)
  ↓
POST /api/tarot/interpret
  { cards: [{ name, number, reversed, position }], question?: string }
  ↓
Spring Boot → Claude API 호출 (claude-sonnet-4-6)
  ↓
한국어 해석 텍스트 반환
```

## 개발 단계

### 1단계 — 정적 텍스트 MVP
- tarot-json 카드 목록 (이름·번호·아르카나·의미 텍스트) 프론트에 번들
- 랜덤 카드 뽑기 (78장 중 중복 없이, 정/역 방향 랜덤)
- 카드 이미지 + 카드명 + 정적 해석 텍스트 표시 (영어 → 한국어 번역본 준비)
- 백엔드 불필요 — 순수 프론트엔드로 구현

### 2단계 — Claude API 해석 (확장)
- `POST /api/tarot/interpret` 엔드포인트 추가
- 뽑힌 카드 정보 → Claude API → 현대적·개인화된 한국어 해석
- 사용자 질문 입력 필드 추가 (선택 사항)
- 상황 맥락 반영한 더 깊은 해석 생성

```

│                                     │
```

## 기술 스택

- **1단계**: 순수 React + tarot-json 로컬 데이터, 백엔드 없음
- **2단계**: Claude API (`claude-sonnet-4-6`) 호출, Spring Boot 엔드포인트 추가
- 카드 이미지: `public/tarot/` 폴더에 정적 파일로 배치

## 카드 선택 & 해석 원칙

### 카드 선택 — 번호 기반 결정론적 랜덤
완전 랜덤이 아니라 사용자 번호로 카드를 결정 → "내 번호가 이 카드를 불렀다"는 느낌.

```
번호 합계 mod 78 = 카드 인덱스
정/역 방향: 번호 합계 홀짝으로 결정
```

번호가 바뀌면 카드도 바뀜 → 재도전 유도.

### 해석 원칙 — 카드는 랜덤, 해석은 항상 희망적
타로에서 "나쁜 카드"는 없음 — 해석하기 나름.  
어떤 카드가 나오더라도 Claude가 건설적·긍정적으로 풀어줌.

```
죽음 카드 → "지금의 것을 내려놓고 새로운 시작을 준비할 때"
탑 카드   → "흔들려야 더 단단해짐. 변화를 두려워하지 말 것"
```

카드 본래 의미는 살리되, 로또 번호 선택 맥락에서 따뜻하게 해석.

### Claude API 프롬프트 방향
```
- 어떤 카드가 나오든 긍정적·건설적으로 해석
- 억지스럽지 않게 카드 본래 상징을 살릴 것
- 사용자의 번호(또는 질문) 맥락을 반영
- 한국어, 따뜻한 톤, 2~3문장
```

## UX 흐름 (로또 연계)

```
로또 페이지에서 번호 선택
        ↓
[이 번호의 운 보기] 버튼
        ↓
"번호의 기운을 읽는 중..." (1~2초)
        ↓
카드 플립 애니메이션
        ↓
카드 이미지 + 카드명
해석 텍스트 (번호 언급 포함)
        ↓
[다른 번호로 다시 보기]  [이 번호 저장하기]
```
