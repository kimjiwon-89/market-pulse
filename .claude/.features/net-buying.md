# 순매수·순매도 순위 기능

**상태**: 구현 완료  
**페이지**: `/net-buy` (NetBuyingList)

---

## 기능 요약

외국인·기관의 날짜 범위별 순매수·순매도 상위 20위를 시계열 테이블로 표시.  
주 단위 네비게이션 + 합계 컬럼(기간 누적 TOP 20)이 핵심.

---

## 필터

| 필터 | 선택지 |
|------|--------|
| 투자자 | 외국인 / 기관 |
| 거래유형 | 순매수 / 순매도 |
| 시장 | 코스피 / 코스닥 / 전체 |

- 기관(INSTITUTION) 선택 시 API 호출 없이 즉시 "준비 중" 표시

---

## 날짜 UI

```
[← 이전주]  [시작일]  ~  [종료일]  [다음주 →]  [오늘]
```

- 기본: 이번주 월~min(오늘, 금)
- `[← 이전주]` / `[다음주 →]`: 현재 시작일 기준 ±7일 (항상 월~금 full week)
- `[오늘]`: 이번주 월~min(오늘, 금) 리셋

---

## 테이블 구조

**항상 타임라인 뷰** — 날짜가 가로 컬럼으로 확장

| 고정 컬럼 | 위치 | 데스크톱 폭 | 모바일 폭 |
|-----------|------|------------|----------|
| 순위 | 좌측 고정 | 44px | 44px |
| 합계 종목명 | 우측 고정 | 110px | 100px |
| 합계 대금(억) | 우측 고정 | 78px | 숨김 |
| 합계 수량(만주) | 우측 고정 | 68px | 숨김 |

- 날짜 컬럼: 각 날짜별 종목명 / 대금(억) / 수량(만주) 3-sub-column
- 오늘 컬럼 강조: "오늘" 텍스트, `--accent-soft` 배경
- 비거래일 컬럼: 전체 로딩 완료 후 데이터 빈 날짜 자동 숨김
- 합계 컬럼: 기간 내 전체 날짜 누적 → 순매수대금 기준 TOP 20 재랭킹

## 종목 상세 모달 (StockModal)

행 클릭 시 슬라이드업 모달:
```
[종목명]  [종목코드]  →종목 상세 페이지 링크
현재가 / 등락률 / 지분률(외국인만, 실시간 데이터에서만)
순매수대금 / 순매수량
메모 (날짜+시장 기준, 로그인 필요)
```

---

## 핵심 유틸

```ts
isWeekday(d)                    // 토/일 제외
getWeekdays(start, end)         // YYYYMMDD 범위 내 영업일 목록
getMondayOf(dateStr)            // 해당 날짜 속한 주의 월요일
getThisWeekBounds(today)        // 이번주 월~min(오늘,금)
shiftWeek(delta)                // ±7일 이동
calcRangeTotal(visibleDates, dataMap)  // 기간 누적 합계 TOP20
```

## 확장 고려

- **기관 데이터** 연동 (현재 "준비 중" 처리)
- 날짜 범위 커스텀 확장 (현재 주 단위 고정)
