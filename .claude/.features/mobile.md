## ⚠️ 네비게이션 구조 개편 (개발 전 재확인 필요)

> **개발 시작 전 반드시 확인** — 레퍼런스 이미지 받은 후 구체화 예정

### 배경

페이지가 늘어나면서 모바일 BottomNav에 메뉴가 너무 많아지는 문제.  
현재 + 예정 메뉴: 대시보드 / 순매수순위 / 투자자동향 / 뉴스 / 로또 / 퀀트모델 / 타로 → **7개**

### 확정 방향: BottomNav 4개 고정 + 더보기(···)

```
[홈]  [퀀트]  [재미]  [··· 더보기]
```

- **홈**: 대시보드
- **퀀트**: 퀀트 모델 (플랫폼 핵심 기능)
- **재미**: 로또 + 타로 묶음
- **···더보기**: 순매수순위 / 투자자동향 / 뉴스 등

데스크톱 사이드바는 섹션 구분선으로 그룹핑:
```
─ 시장 분석 ─        ─ 퀀트 ─        ─ 재미 ─
대시보드              퀀트 모델        로또
순매수순위                             타로
투자자동향
뉴스
```

### 미결정 (레퍼런스 받은 후 결정)

- BottomNav 탭 구성 최종 확정
- "더보기" 형태 — 슬라이드업 시트 vs 드롭다운 vs 별도 페이지
- "재미" 탭 아이콘·명칭
- 레퍼런스: **사용자가 추후 제공 예정**

## 페이지별 작업 우선순위

| 순위 | 페이지 | 주요 작업 |
|------|--------|-----------|
| 1 | DefaultLayout + Nav + BottomNav | 전 페이지 영향 — 먼저 완료 필수 |
| 2 | Dashboard | stat-grid 2×2, grid-12 → 단일 컬럼 |
| 3 | InvestorTrend | 필터 탭 스크롤, 테이블 → 카드 |
| 4 | StockDetail | KPI 2×2, 차트 높이 축소 |
| 5 | NetBuyingList | 가로 스크롤 유지, 날짜 선택기 레이아웃 |
