# 로또 머신러닝 예측 및 통계 분석 정리

## 개요

로또 머신러닝 예측은 과거 회차 데이터를 기반으로 다음 회차에 나올 가능성이 상대적으로 높은 번호 패턴을 추정하는 방식이다.

다만 로또는 기본적으로 독립 난수(Random) 기반이므로 실제 미래 번호를 정확하게 예측하는 것은 사실상 불가능에 가깝다.

따라서 실제 프로젝트에서는:

- 패턴 분석
- 통계 기반 가중치
- 조합 최적화
- 번호 경향 탐색
- 이상 조합 제거

위 목적에 더 가깝게 사용된다.

# 머신러닝 접근 방식

## 1. 빈도 기반 모델

가장 기본적인 방식.

최근:

- 10회
- 30회
- 50회
- 전체 회차

등을 기준으로 번호 출현 빈도를 계산한다.

### 예시 분석

- 최근 급등 번호
- 장기 미출현 번호
- 특정 번호 구간 출현 증가
- 홀짝 비율
- 고저 비율

### 예시

```text
7번 최근 20회 동안 6회 등장
32번 최근 50회 동안 미출현
```

---

## 2. 마르코프 체인

이전 회차의 패턴이 다음 회차에 영향을 준다고 가정한다.

### 예시

- 특정 번호 다음에 자주 등장하는 번호
- 특정 번호쌍 동반 출현
- 번호 구간 이동 패턴

### 활용

전이 확률 기반 번호 가중치 계산.

---

## 3. 시계열 분석

번호 흐름을 시간 데이터처럼 분석한다.

### 사용 모델

- ARIMA
- Prophet
- LSTM

### 단점

로또는 랜덤성이 너무 강해 시계열 연속성이 약하다.

실전 성능은 높지 않은 편.

---

## 4. 딥러닝 모델

### 입력 데이터 예시

- 최근 N회 번호
- 번호 출현 빈도
- 번호 간 거리
- 번호 합계
- 홀짝 비율
- 연속 번호 여부
- 끝수 패턴

### 출력

다음 회차 번호 확률 또는 추천 조합.

### 사용 기술

- TensorFlow
- PyTorch

---

## 5. 유전 알고리즘

로또 프로젝트에서 은근히 많이 사용되는 방식.

### 동작 방식

1. 랜덤 번호 생성
2. 점수 계산
3. 좋은 조합끼리 교배
4. 반복 진화

### 목표

과거 당첨 패턴과 유사한 조합 탐색.

---

## 6. 강화학습

이론상 가능하지만 실효성은 낮다.

### 이유

- 보상이 너무 희소함
- 데이터 부족
- 랜덤성이 강함

---

# 실제 핵심은 Feature Engineering

실제로 가장 중요한 부분.

머신러닝 모델보다 입력 특징(Feature) 품질이 더 중요하다.

---

# 주요 Feature 목록

## 번호 합계

```text
예: 154
```

보통 특정 범위의 합계가 자주 등장.

---

## 홀짝 비율

```text
3:3
4:2
2:4
```

극단적인 비율은 드물다.

---

## 고저 비율

예:

- 저구간: 1~22
- 고구간: 23~45

---

## 연속 번호 개수

예:

```text
11,12
23,24,25
```

---

## 끝수 패턴

예:

```text
1,11,21,31
```

같은 끝수 과다 여부 분석.

---

## 장기 미출현 번호

최근 N회 동안 등장하지 않은 번호.

---

## 최근 급등 번호

짧은 기간 동안 자주 등장한 번호.

---

## 번호 표준편차

번호 분산 정도 계산.

---

## 번호 간 거리

정렬된 번호 간 간격 분석.

예:

```text
3, 7, 15, 16, 31, 45
```

거리:

```text
4, 8, 1, 15, 14
```

---

# Feature 테이블 예시

| 회차 | 합계 | 홀짝비율 | 연속번호 | 저구간수 |
|---|---|---|---|---|
| 1150 | 154 | 3:3 | 1 | 2 |

# 통계 기반 추천 방식

실제 프로젝트에서는 머신러닝 단독보다:

```text
통계 + 머신러닝 혼합
```

방식을 가장 많이 사용한다.

# 현실적인 결론

로또는 기본적으로 랜덤성이 매우 강하다.

따라서:

- 미래 번호를 정확히 예측하는 것은 현실적으로 매우 어렵다.
- 머신러닝도 실제 예언보다는 통계 분석 도구에 가깝다.
- 다만 이상 조합 제거 및 균형 잡힌 번호 추천에는 의미가 있다.
- 프로젝트 관점에서는 데이터 분석 및 시각화 학습용으로 매우 재미있는 주제다.
