🎯 프로젝트 개요
"통계로 세상을 읽는 분석 플랫폼" — 단순 데이터 조회가 아닌 통계 모델 기반 인사이트 제공
플랫폼 정체성

한국투자증권 Open API(KIS)와 KRX Open API에서 실시간·히스토리컬 데이터를 수집하고, 통계 모델을 적용해 투자자에게 인사이트와 실험의 재미를 동시에 제공한다.


모든 콘텐츠는 공개 데이터 수집 → 통계 모델 적용 → 결과 시각화 + 사용자 실험 → 누적 성적 추적 패턴을 따른다. 퀀트 트레이드에서 시작했으나, 통계 기반이라면 주식 외 어떤 도메인으로도 확장 가능하다.

토큰 관리 3단계 캐싱 (KIS API)
KIS API 인증 토큰을 Redis → DB → 신규 발급 순으로 3단계 캐싱. Redis 우선 조회 → 유효하면 반환 → 없으면 DB 조회 → 유효하면 Redis 저장 후 반환 → 없으면 KIS 신규 발급 → DB + Redis 모두 저장.
공통 응답 형식
// 성공
ApiResponse.success(data)

// 실패 — error() 아님, failure() 사용
ApiResponse.failure("message")

🎰 로또 분석 연구소 백엔드 완료 / 프론트 예정
경로: /lotto — 5가지 통계 전략으로 번호 풀 생성 + 성적 추적
단순 번호 추천기가 아닌 전략별 누적 성적 추적 연구소. 백테스트 결과 MOMENTUM 22.9%가 현실적 상한 (랜덤 기대값 22.2% 대비 +3.1%). 번호 적중보다 전략 성적 시각화 콘셉트에 집중.
5가지 분석 전략
#전략컨셉구성 원소
1모멘텀최근 빈도 높고 상승 추세인 번호HOT + RISING
2잠수함장기 미출현 + 최근 더 줄어드는 번호COLD + FALLING
3관계망함께 자주 나오는 동반번호 네트워크동반번호 + 연속번호
4위치 패턴강세 번호대·끝자리 흐름끝수 + 구간
5AI 스마트픽전략 1~4 가중합 종합 추천밸런스 + 역배 + CORE + AI종합
핵심 흐름
매 회차 토요일 21:30 스케줄러 실행
→ 전략 5개 × 번호 풀 10개 계산
→ 각 풀에서 추천 조합 3개 생성
   필터: 합계 100~175 / 홀짝 편차 ≤2 / 4구간 이상 / 3연속 금지
→ 당첨 번호 수집 → 풀·조합 적중률 자동 비교 저장

⚠️ 구현 시 주요 주의사항
  • 수치는 반드시 IBM Plex Mono — .mono 클래스 또는 font-family: var(--font-mono)
  • 상승/하락 색상 — dirCls(n) → "up" | "down" | "flat" className으로 처리
  • aria-pressed — 칩 토글 / aria-selected — 탭 / aria-current="page" — 사이드바 활성
  • 터치 타겟 최소 높이 44px (min-h-[44px])
  • 복잡한 테이블(NetBuyingList)은 카드 변환 대신 overflow-x-auto 가로 스크롤
  • padding 단축속성 금지 (BottomNav 여백 필요한 컨테이너에서) — bottom은 Tailwind pb-* 클래스로
  • LiveBadge — 장중/종가 표시가 필요한 모든 곳에 <LiveBadge /> 사용
  • sessionStorage — 페이지 간 상태 전달 (mp:flow:initDate, mp:flow:initMarket)
