우선순위작업구현 내용완료 기준
P0 KIS 1분봉 차트 FHKST03010200 당일분봉을 /api/stock/minute-chart로 정규화합니다. 삼성전자 기준 1분봉 OHLCV가 프론트 차트에 표시됩니다.
P0 호가/예상체결 FHKST01010200으로 매수/매도 호가 10단계와 예상체결을 조회합니다. 차트·호가 탭에서 로그인 없이 조회용 호가판을 볼 수 있습니다.
P0 종목 터미널 UI 기존 /stock/:code를 차트·호가, 종목정보, 뉴스·공시, 거래현황 탭 구조로 확장합니다. 현재 페이지의 기본 KPI를 유지하면서 토스형 정보 구조가 생깁니다.
P0 조건부 OpenDART 공시 OpenDART API 키가 있으면 공시 목록과 원문 XML 링크를 제공합니다. API 키 미설정 시 화면은 비활성 안내를 표시하고 서버는 명확한 실패 메시지를 반환합니다.
P1 뉴스·리포트 메타 KIS 뉴스 제목, KIRS/FnGuide/WiseReport 후보 메타데이터 구조를 설계합니다. 저작권 있는 PDF 전문을 복제하지 않고 링크·요약·태그 중심으로 저장합니다.
P1 분봉 저장 stock_minute_bar 테이블과 upsert 수집 흐름을 추가합니다. 사용자가 조회한 종목의 당일 1분봉이 DB에 누적됩니다.

안 되는 것과 되게 하는 방향

막힘왜 지금 안 되는가되게 하는 방향
과거 전체 1분봉 KIS 당일분봉 API는 당일 데이터 중심이고 호출당 최대 30건입니다. 오늘부터 자체 저장을 시작하고, 과거 백필은 KRX/Koscom 또는 유료 벤더 계약을 검토합니다.
증권사 리포트 전문 복제 공개 PDF라도 저작권과 재배포 권리가 별도입니다. 메타데이터·링크·자체 요약만 저장하고, 전문 저장은 계약된 소스만 허용합니다.
토스와 완전히 동일한 데이터 토스 내부 제휴 데이터와 자체 가공 데이터는 공개 API가 아닙니다. KIS/OpenDART/KRX로 재현 가능한 항목을 먼저 채우고, FnGuide/WiseReport 제휴로 컨센서스를 보강합니다.
실제 주문 Market Pulse는 퀀트 정보 서비스이며 거래 실행 권한을 두지 않습니다. 모의 주문/관찰용 주문 패널까지만 두고 실제 주문 API는 연결하지 않습니다.
