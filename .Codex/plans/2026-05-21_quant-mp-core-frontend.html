1. 개요

기존 MP_CORE 대시보드는 기능 검증은 통과했지만, 퀀트 지표를 모르는 사용자가 실전 판단을 내리기 어렵다. 이번 리플랜은 기존 기능을 유지하면서 첫 화면에 초보자용 판단 레이어를 추가한다.

핵심 질문

지금 사도 되는가, 기다려야 하는가, 보유 중이면 줄여야 하는가를 바로 보여준다.

표현 방식

신호등 배지, 오늘 할 일 카드, 위험 미터, 쉬운 이유 카드, 도움말을 사용한다.

정량 정보

factor, score, backtest 상세는 숨기지 않고 고급 보기로 이동한다.

트레이드오프: 쉬운 표현은 판단 속도를 높이지만 중요한 수치 맥락을 가릴 수 있다. 따라서 기본 화면은 쉬운 행동 중심, 상세 지표는 `고급 지표 보기`에 둔다.

6자세한 수치도 보고 싶다`고급 지표 보기`를 열어 기존 factor/backtest/diagnostics 확인

5. API 설계

기존 MP_CORE API 경로를 유지한다. 초보자용 상태와 문구는 프론트엔드에서 기존 필드를 조합해 계산한다.

API사용 필드용도
기존 후보 목록 APIcandidateStatus, nextAction, rebalanceStatus, blockers, riskFlags, reasonChips, triggerConditions, currentWeight, targetWeight쉬운 판단, 오늘 할 일, 위험, 이유 계산
기존 후보 상세 API동일드릴다운 상세와 고급 보기
기존 백테스트 APImonthlyReturn, totalReturn, mdd, totalCost, 상세 지표월평균 수익률, 전체 수익률, 최대 하락 경험, 거래 비용 표시
기존 diagnostics APIfeature/factor/sector 관련 상세 지표고급 지표 보기
백엔드 변경은 기존 응답에 판단 근거 필드가 없을 때만 optional 필드 추가로 제한한다. 신규 엔드포인트는 만들지 않는다.
