개요
이 문서는 퀀트 모델 홈과 beginner-facing quant 화면의 binding design guide다.
기준 목업 유지
비율, 밀도, 좌측/우측 구성은 승인된 목업을 기준으로 한다.
모노톤 UI
기본 UI는 흰색/회색/차콜이며 blue는 작은 action point로만 쓴다.
쉬운 퀀트 설명
`퀀트 모델` 키워드는 유지하되 첫 화면 언어는 초보자도 이해해야 한다.
기준 목업
이 이미지를 desktop ratio, density, right rail, stock badge의 기준으로 사용한다.
제품 의도
홈은 마케팅 페이지가 아니라 오늘의 퀀트 모델 판단을 설명하는 실사용 화면이다.
Required Main Copy
퀀트 모델이 고른 오늘의 종목
매일 시장 데이터를 계산해 살펴볼 종목, 기다릴 종목, 조심할 종목을 쉽게 정리합니다.
First Screen Must AnswerMeaning
오늘 어떤 종목을 보면 되는가daily decision list
왜 그렇게 판단했는가plain-language reasons
어떤 점을 조심해야 하는가risk/caution explanation
어떤 모델이 판단했는가model source or several-model state
과거 검증 근거는 있는가validation/report entry
