## 결론

현재 방향은 잘못 잡혀 있었다. `KOSPI_BULL`, `KOSDAQ_BULL`는 장중 1분봉 감시 모델이 아니라 일봉 랭킹 기반 후보 생성에 가까웠고, 2026-06-01 같은 장에서는 시초가 갭, 테마 확산, 장중 거래대금 폭증을 실시간으로 못 잡는 구조였다.

수정 방향은 `1분봉 전종목 감시 -> 후보 상태 계속 갱신 -> 확정 신호만 진입 -> 진입 후 리스크/재진입 통제 -> 장마감 학습 라벨 저장`이다.

## 왜 놓쳤나

1. 후보 엔진이 전체 시장 1분봉을 보지 않았다.
   - 기존 후보는 `CHANGE_RATE_DESC` 일봉 랭킹 중심이었다.
   - 삼성전자처럼 대형 거래대금 상위, 장중 추세형 종목은 등락률 상위 소수 필터에서 빠질 수 있었다.

2. 시초가 갭/동시호가 감시가 없었다.
   - LG전자는 전일 종가 293,000원 대비 09:02 첫 유효 분봉이 369,000원이었다.
   - 이미 +25.94%로 시작한 종목이라 장중 일반 스캐너보다 `08:50-09:05 pre-open/opening gap` 감시가 먼저 필요했다.

3. 테마 클러스터 감시가 없었다.
   - LG전자 단독이 아니라 LG헬로비전, LG전자우, LG씨엔에스, LG, LG이노텍, 로보스타, 두산로보틱스, 레인보우로보틱스까지 확산된 장이었다.
   - 모델은 종목 단일 스코어만 보고 테마 자금 확산을 후보 승격 조건으로 쓰지 않았다.

4. 당일 데이터 업데이트 신뢰성이 깨져 있었다.
   - 운영 랭킹 API가 요청 날짜와 다른 과거 날짜를 반환했다.
   - 이 상태에서는 오늘 후보/어제 분석/실시간 후보가 모두 오염될 수 있다.

## 실시간 엔진 설계

### 1. 데이터 수집

- 08:50-09:00: 동시호가/예상체결, 전일 대비 예상 갭, 예상 거래대금
- 09:00-15:30: 전종목 1분봉 또는 KIS 실시간 체결 WebSocket
- 1분마다 저장: 현재가, 등락률, 분당 거래량, 누적 거래대금, VWAP, 고가 근접도, 전일 거래량 대비 속도
- 뉴스/테마: 종목명, 그룹명, 키워드, 관련주 그래프

### 2. 후보 상태

```text
NONE -> WATCH -> HOT -> ENTRY_READY -> ENTERED -> EXITED/COOLDOWN
```

- `WATCH`: 갭, 거래대금, 뉴스, 테마 중 하나 감지
- `HOT`: 1분 거래대금/등락률/테마 확산 동시 충족
- `ENTRY_READY`: 2-3개 분봉 연속 확인, VWAP 위, 고가 돌파 또는 눌림 후 재돌파
- `ENTERED`: paper/live 주문 가능 상태
- `COOLDOWN`: 당일 중복 진입 차단

### 3. 진입 신호

- 대형주 안정형: 거래대금 상위 20, 전일 대비 +3%, +5% 돌파, VWAP 위, 5분 고점 재돌파
- 테마 후속형: 테마 리더 상한가 또는 +20%, 관련주 3개 이상 동시 상승, 본주 고갭이면 proxy 종목 우선
- 장중 급등형: 갭 10% 이하, 10분 누적 +5% 이상, 분당 거래량 상위 5%, 고가권 유지
- 추격 금지: 시초 갭 +20% 이상이고 상한가 근접한 본주는 즉시 매수하지 않고 proxy/눌림만 감시

### 4. 학습 라벨

- `high_gap_limit_leader`: LG전자, LG씨엔에스, 로보스타
- `theme_spread_best_entry`: LG헬로비전, LG전자우
- `large_liquid_momentum`: 삼성전자, 삼성전자우, 삼성에스디에스
- `intraday_efficiency_breakout`: 한국비티비, 크라우드웍스, 크레오에스지
- `failed_theme_follow`: LG디스플레이, LG이노텍

## 구현 우선순위

1. 날짜 신뢰성 차단
   - 요청 날짜와 응답 tradeDate가 다르면 API가 실패하도록 막는다.

2. 1분봉 저장 테이블 추가
   - `quant_intraday_bar`
   - `quant_intraday_candidate_snapshot`
   - `quant_intraday_signal_event`

3. 실시간 스캐너 추가
   - 1분마다 전종목 또는 랭킹 상위+관심 테마 종목 갱신
   - 후보 상태를 upsert하고 화면은 polling/SSE로 갱신

4. 모델 분리
   - `KOSPI_BULL_DAILY`: 기존 일봉/지연 진입
   - `KOSPI_INTRADAY_MOMENTUM`: 삼성전자형 대형주 장중 추세
   - `THEME_INTRADAY_SPREAD`: LG/로봇형 테마 확산
   - `KOSDAQ_INTRADAY_BREAKOUT`: 갭 낮은 코스닥 장중 급등

5. 장마감 학습
   - 상한가/급등주를 라벨링
   - 실제 후보 누락 여부 기록
   - 다음 거래일 룰/가중치 shadow 반영

## 학습 반영 요약

오늘부터 모델은 `등락률 상위 몇 개`만 보면 안 된다. 반드시 아래 네 축을 같이 봐야 한다.

1. 시초가 전 갭/예상체결
2. 1분봉 거래대금 가속
3. 테마/그룹 확산
4. 대형주 안정 추세
